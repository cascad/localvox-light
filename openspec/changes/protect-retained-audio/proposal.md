# Сохранять исходное аудио до подтверждённой расшифровки

BL-020: **implemented / tested in source tree**. Delta синхронизирована;
установленный release не обновлён. [Evidence](../../evidence/implementation-review-2026-09-27.md).

## Why

Принят DEC-001: исходники хранятся до ручного удаления по умолчанию. При обнаружении
CLI включал retention на 14 дней, а sweep удалял старые файлы без проверки STT (RV-004).

## What Changes

- Отключить автоматическую очистку по умолчанию (days=0), сохранив явную настройку срока.
- При включённой очистке удалять старые аудиофайлы только у закрытой, не занятой
  обработчиком сессии с подтверждённой и проверенной расшифровкой.
- При недоступной/повреждённой очереди или результате сохранить исходник.
- Не менять явно заданные настройки и не выполнять очистку пользовательского архива
  в рамках разработки: проверки проводятся на временном хранилище.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `audio-storage`: STORE-003 — default и условия безопасной автоматической очистки.

## Impact

CLI, chunks retention, пример конфигурации, тесты отказов на временном архиве.
Основание: [DEC-001](../review-code-inventory/proposal.md#dec-001), RV-004;
текстовая обработка после очистки поддерживается BL-007.
