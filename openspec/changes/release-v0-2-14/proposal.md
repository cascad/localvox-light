# Выпуск LocalVox v0.2.14

## Why

Пользователям установщика нужны исправления захвата звука и управления записью, которые вошли в main после v0.2.13.

## What Changes

- Выпустить проверенные изменения [захвата аудио](../fix-macos-capture-feedback/evidence/implementation.md) и [терминального управления записью](../surface-terminal-record-controls/evidence/implementation.md).
- Обновить версию в Cargo, UI и Tauri. Запустить публикацию комплектов Windows x64, macOS Apple Silicon и Intel, Linux x64 и ARM64 существующим процессом выпуска.

## Capabilities

Выпуск объединяет уже реализованные изменения. Требования к самому процессу поставки сохраняются.

## Impact

Команда установки получит v0.2.14 после успешной публикации комплектов и скриптов на GitHub.
