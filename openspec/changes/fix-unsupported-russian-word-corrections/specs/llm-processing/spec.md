## MODIFIED Requirements

### Requirement: LLM-003 Refine и cleanup по строкам

Refine SHALL выдавать новую версию; cleanup — processed.json с source version и поправками строк. Размеры пакетов ограничиваются числом строк и символами; одна слишком длинная строка идёт отдельно. Имена/разметка/времена берутся из транскрипта, не сочиняются cleanup-моделью; пропущенная или отвергнутая поправка сохраняет исходную строку.

Система SHALL сохранять исходное содержание каждой строки: отклонять потерю
смысловых оговорок/отрицаний, изменение буквального содержимого цитат и приписывание
соседней реплики. Консервативный отказ от сомнительной правки сохраняет исходник;
успешное завершение модели само по себе не доказывает смысловую корректность.

Код: [process_session, refine_session](../../../../../crates/localvox-light-llm/src/pipeline.rs), [save](../../../../../crates/localvox-light-core/src/readable.rs).
Существующая проверка: `an_essay_instead_of_the_lines_costs_the_cleanup_not_the_text`, `lines_the_model_never_answered_for_keep_their_own_wording`, `one_oversized_line_goes_alone_rather_than_in_half`.

#### Scenario: Модель написала эссе

- **WHEN** ответ не содержит допустимых поправок строк
- **THEN** исходный текст не заменяется эссе.

#### Scenario: Пропущенная строка

- **WHEN** модель не вернула поправку на строку
- **THEN** в читаемом результате остаётся исходная формулировка.

#### Scenario: Оговорка и цитата остаются содержанием

- **WHEN** модель убрала «почти»/«пока» либо буквальное «эээ» внутри цитаты
- **THEN** исходная строка сохраняется вместо такой правки.

#### Scenario: Соседняя реплика не переносится

- **WHEN** в исправленную строку дописано содержание соседней реплики
- **THEN** эта поправка отклоняется, а номера, времена и обе исходные реплики сохраняются.

#### Scenario: Полезное ограниченное исправление

- **WHEN** модель исправила явную опечатку, регистр или однозначную вокальную паузу без изменения содержания
- **THEN** допустимая правка принимается с прежней привязкой к строке.

#### Scenario: Неоднозначный номер строки

- **WHEN** ответ содержит несколько вариантов одного исходного номера
- **THEN** эта поправка отклоняется с учётом rejected, исходная строка сохраняется, а допустимые ответы других номеров остаются доступными.

#### Scenario: Близкое существующее слово не доказывает исправление

- **WHEN** модель заменяет существующее русское слово близким по написанию, но однозначной ошибки и допустимости замены не установлено
- **THEN** исходная строка сохраняется, включая воспроизведённые неподтверждённые изменения падежа.

#### Scenario: Однозначное локальное согласование

- **WHEN** явное подлежащее и форма того же глагола однозначно подтверждают исправление согласования без смены времени или содержания
- **THEN** ограниченная полезная поправка принимается с прежней привязкой к строке; неоднозначность сохраняет источник.
