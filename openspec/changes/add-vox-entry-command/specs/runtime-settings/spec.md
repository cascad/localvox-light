# Spec Delta

## ADDED Requirements

### Requirement: RUN-005 vox открывает TUI и подключает демон

Команда vox без аргументов SHALL открывать TUI. Она SHALL использовать настройки
своей установки независимо от текущего каталога и LOCALVOX_LIGHT_TUI. Существующий
совместимый демон SHALL использоваться повторно. Запуск соседнего демона SHALL
допускаться только при подтверждённом отказе соединения с локальным адресом;
занятый, несовместимый, удалённый или неавторизованный API SHALL не подменяться
новым процессом. Клиент SHALL не запускать собственный capture engine.
Обычный выход SHALL сохранять существующее поведение отдельного TUI-клиента.

Код: [entry](../../../../../crates/localvox-light-terminal/src/entry.rs),
[launcher](../../../../../crates/localvox-light-terminal/src/launcher.rs).
Проверки: [coverage](../../../../evidence/coverage.md).

#### Scenario: Демон отсутствует
- **WHEN** vox запущена в интерактивном терминале, локальный API отказывает в соединении
- **THEN** клиент делает одну попытку запуска соседнего демона и ожидает готовность с ограничением времени.

#### Scenario: Демон уже работает
- **WHEN** совместимый API отвечает
- **THEN** vox открывает TUI существующего демона без нового захвата и второго процесса демона.

#### Scenario: Каталог и параметры
- **WHEN** vox запускается из другого каталога или переданы явные параметры подключения
- **THEN** настройки установки загружаются до разбора env-параметров; явный адрес сильнее настроек, а caller files не подменяют установку.
