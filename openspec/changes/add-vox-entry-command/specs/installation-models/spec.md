# Spec Delta

## ADDED Requirements

### Requirement: SETUP-007 Короткая команда vox

Полный комплект Windows/macOS/Linux SHALL содержать native команду vox.
Установщик SHALL по умолчанию регистрировать её в пользовательском PATH без admin;
opt-out SHALL оставлять запуск из папки установки. Существующая чужая vox SHALL
не перезаписываться и не скрываться без сообщения о конфликте. Повтор и read-only
проверка SHALL сохранять уже готовые файлы и настройки без дублей PATH. Shell startup
files SHALL сохранять остальное содержимое, права и существующие ссылки; ошибка
публикации SHALL не оставлять частично записанный профиль. Поддерживаемые Unix
оболочки — Bash, Zsh, Fish; иной shell требует явной инструкции, а не ложного успеха.

Код: [entry](../../../../../crates/localvox-light-terminal/src/entry.rs),
[регистрация](../../../../../crates/localvox-light-terminal/src/command_path.rs).
Проверки: [coverage](../../../../evidence/coverage.md).

#### Scenario: Первая установка
- **WHEN** устанавливают полный комплект без opt-out и без конфликта имени
- **THEN** vox доступна в новом терминале; сохранены прежние элементы PATH и настройки пользователя.

#### Scenario: Конфликт команды
- **WHEN** vox уже принадлежит другой программе в PATH
- **THEN** её файлы и настройки сохраняются; установщик сообщает конфликт и путь к локальной vox.

#### Scenario: Повтор и проверка
- **WHEN** регистрацию выполняют повторно либо запускают read-only проверку
- **THEN** готовая регистрация не переписывается и не дублируется; проверка не создаёт профилей и каталогов.

#### Scenario: Ошибка профиля или иной shell
- **WHEN** профиль изменился одновременно, публикация недоступна или shell не поддержан
- **THEN** исходные данные не заменяются частичным файлом; причина и способ запуска из установленной папки видны пользователю.
