# Навигация до загрузки данных — 2026-11-21

RUN-005 (delta), US-061. По отзыву владельца j/k и стрелки в меню разделов
не работали сразу после запуска, пока он не переключил область через Tab.

## Причина и изменение

Read-only проверка уже исправленного демона F:\lv: health успешен, список сессий
содержит 0 записей. Начальный focus=1 направлял команды в пустой список, хотя
в меню сохранялась выбранная строка «Архив». При готовности API reconnected
дополнительно заменял всю модель и возвращал focus=1/nav=0. Первая загрузка сессий
через select_session также безусловно возвращала nav=0.

Общий terminal entry теперь начинает с focus=0 — меню разделов. Навигация
view/tab/focus/nav переживает готовность/смену подключения, сохраняя существующее
правило очистки серверных документов и неподтверждённых команд. Автоматический
выбор первой записи не меняет курсор меню уже открытого архива. Явный переход
к записи из другого раздела продолжает выбирать «Архив». Таймеров/Tab-инъекций,
автоматической смены фокуса после загрузки и специальных правил терминала нет.

  включая первый непустой список и подключение в уже выбранных «Заметках».
