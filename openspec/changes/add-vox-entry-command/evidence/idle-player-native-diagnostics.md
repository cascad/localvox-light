# Пустой плеер и проверочные DLL-ошибки — 2026-11-21

RUN-005 (delta), ARCH-002, US-015. До выбора записи TUI показывал
«00:00 / — волна загружается…», хотя запрос формы аудио не запускался.
Владелец также прислал окно localvox-api.exe с отсутствующей libvosk.dll.

Плеер без current теперь показывает «Выберите запись для прослушивания».
Это исправление неверного состояния загрузки; волна относится к аудио,
а не к загрузке модели. Для выбранной записи сохранены различимые pending,
ошибка и пустой результат. Звук/позиция/документы и геометрия панели не менялись.

DLL-окно соответствует предыдущему проверочному standalone API-запуску,
у которого не был задан native DLL path; последующий корректный запуск уже
прошёл. При новом осмотре процесса и окна ошибки не было — агент не утверждает,
что закрыл их сам. В установленном продукте отдельный localvox-api не запускается.

В maintained check-release-install.py добавлен scoped error-mode guard:
SEM_FAILCRITICALERRORS/SEM_NOGPFAULTERRORBOX наследуются проверочными дочерними
процессами, прежнее значение восстанавливается в finally. Ошибка загрузчика
0xC0000135 остаётся отказом, но сообщается текстом, без системной модалки.
Правило native DLL окружения описано в installer-testing.md. Новый delivery
test входит в существующий CI glob и добавлен в path trigger.
