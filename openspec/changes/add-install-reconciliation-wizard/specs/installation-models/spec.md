## ADDED Requirements

### Requirement: SETUP-005 Read-only setup report

Doctor/setup check SHALL использовать фактические runtime rules разрешения путей,
выдавать стабильные component IDs, причины и доступный JSON report. Check MUST NOT
скачивать, распаковывать, менять конфигурацию, устанавливать или запускать службы.
Установленная CLI Ollama, отвечающий API и наличие выбранной модели SHALL быть
различимыми состояниями, а не одним успешным TCP-connect.

#### Scenario: Existing external models
- **WHEN** настроенные рабочие модели находятся вне каталога установки
- **THEN** check показывает эти пути и не предлагает второе скачивание как обязательное.

#### Scenario: Missing server or model
- **WHEN** Ollama установлена, но API недоступен либо выбранного tag нет
- **THEN** report различает эти причины, не выдавая модель за готовую.

#### Scenario: Check before first installation
- **WHEN** установщик запущен в check mode без установленного продукта
- **THEN** сообщает отсутствие продукта без создания файлов и скачивания пакета.

### Requirement: SETUP-006 Повторяемый терминальный мастер

Мастер SHALL показывать обнаруженное состояние, предлагать существующие ASR paths
или скачивание выбранных компонентов, существующий Ollama tag/pull/GGUF import
либо свой сервер/отказ от LLM. Перед действиями SHALL показывать план и требовать
подтверждение. Reconcile SHALL переиспользовать исправный bundle, модели и
настройки; повтор без изменений не выполняет download/unpack/pull/import/save.

#### Scenario: Confirm and cancel
- **WHEN** пользователь отменяет план до подтверждения
- **THEN** конфигурация и установленные компоненты остаются неизменными.

#### Scenario: Existing models and Ollama
- **WHEN** нужные модели и tag уже есть и пользователь сохраняет найденный выбор
- **THEN** повторный прогон не устанавливает Ollama, не скачивает модели и не переписывает .env.

#### Scenario: Select model source
- **WHEN** пользователь выбирает готовый ASR directory или GGUF файл
- **THEN** ASR directory проверяется теми же правилами doctor и используется без копирования; GGUF импортируется через Ollama только с явно выбранным новым tag и понятной ценой хранения.

#### Scenario: Optional Ollama installation
- **WHEN** Ollama отсутствует и пользователь подтверждает её установку
- **THEN** запускается официальный установщик, существующая установка/служба не заменяется; после завершения отдельно проверяются API и модель.

#### Scenario: Partial failure and retry
- **WHEN** загрузка, запуск установщика или pull завершается ошибкой
- **THEN** ошибка не становится успехом; следующий запуск сохраняет готовую работу и повторяет только недостающее.
