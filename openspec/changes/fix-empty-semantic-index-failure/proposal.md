# Proposal

## Why

BL-005 воспроизвёл нарушение SEARCH-002: при HTTP 503 embeddings и отсутствии
готовых векторов SemanticIndex пропускает сессию, затем search возвращает пустой
список. Отказ сервиса выглядит как отсутствие совпадений. Исходный native отказ:
`target/bl005-unavailable.log`, assertion `semantic.is_err()`.

## What Changes

- Сохранить причину неудачной векторизации и вернуть её, если после обновления
  нет ни одного доступного документа. Пустой архив без ошибки остаётся пустым.
- Сохранить успешные и прежние доступные векторы при частичном отказе; lexical
  остаётся независимым, hybrid использует доступный канал.
- Закрепить воспроизведение HTTP/native тестом, успешное восстановление и чтение
  документов; ошибки не менять на искусственные «нет результатов» ради теста.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `search-chat`: SEARCH-002, явный сценарий отказа при пустом semantic после
  неудачной векторизации; действующее требование сообщать ошибку сохраняется.

## Impact

SemanticIndex::open_or_update, HTTP поиск, evidence BL-005/SEARCH-002. Новых
зависимостей и форматов нет. Работающий демон/архив владельца не изменяются.
