# Spec Delta

## MODIFIED Requirements

### Requirement: SEARCH-002 Режимы и деградация

search_mode SHALL возвращать пустой список на пустой запрос без вызова embeddings, ограничивать API limit диапазоном 1–50. semantic сообщает свою ошибку; hybrid независимо обрабатывает ошибки каналов и сливает доступные результаты RRF с дедупликацией. При отказе обоих каналов API SHALL вернуть ошибку недоступности поиска. «Ничего не найдено» допустимо только после успешного поиска; ошибка поиска SHALL не превращаться в ответ чата об отсутствии информации.

Код: [Archive](../../../../../crates/localvox-light-api/src/archive.rs).

#### Scenario: Ollama недоступна

- **WHEN** hybrid получил рабочие лексические результаты и ошибку semantic
- **THEN** выдаются лексические результаты.

#### Scenario: Оба канала отказали

- **WHEN** оба канала hybrid завершились ошибкой
- **THEN** API сообщает отказ поиска, а чат не выдаёт его за отсутствие данных и не вызывает LLM.

#### Scenario: Пустой индекс после отказа embeddings

- **WHEN** обновление семантического индекса не смогло получить embeddings и доступных векторов не осталось
- **THEN** semantic возвращает ошибку с причиной отказа; lexical остаётся доступен, hybrid использует его результаты. Пустой архив без ошибки возвращает пустой список.
