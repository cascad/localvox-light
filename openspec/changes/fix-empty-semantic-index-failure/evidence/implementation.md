# RV-017: отказ embeddings не равен пустому поиску — 2026-11-01

Принятое требование: [SEARCH-002](../../../specs/search-chat/spec.md#requirement-search-002-режимы-и-деградация).
Воспроизведено в [BL-005 native](../../verify-background-indexing/evidence/implementation.md):
новый временный архив с проверенной расшифровкой, `/api/embed` отвечает 503,
worker пропускает сессию, API semantic ошибочно возвращает пустой список.
Assertion `api.client.search("бюджет", "semantic").is_err()` до исправления — FAIL,
exit 101 (`target/bl005-unavailable.log`). Lexical при этом уже работал.

[Исправление](../../../../crates/localvox-light-search/src/semantic.rs) сохраняет
первую embed-ошибку при обходе и возвращает её, когда доступных docs нет. Другие
сессии продолжают сканироваться, прежний кеш сохраняется. Легитимный пустой архив
без ошибки возвращает пустой ответ без запроса к endpoint. Формат индекса и модель
не менялись. Контракт не ослаблен под дефект.

После пересборки настоящего worker native scenario unavailable — PASS: HTTP 503,
connection refused, lexical/hybrid, чтение документов, отсутствие запроса для
пустого архива, восстановление, сохранение прежних векторов при неудачном update,
новый best после повторного восстановления. Полный BL-005 — **5 passed**, 14.32 s.
Дополнительно search lib **11 passed**, API lib **76 passed, 6 ignored**.

Команды, файлы тестов и пределы проверки — в BL-005 report. Синтетические
embeddings не доказывают качество retrieval; пользовательский архив и работающий
демон не менялись. Исходная ручная приёмка UI/TUI остаётся открытой.
