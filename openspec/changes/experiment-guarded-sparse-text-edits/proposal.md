# Proposal

## Why

Владелец 2026-11-02 разрешил попробовать другой подход к правке, особо указав риск
плохих ответов слабой локальной модели. [Измерение BL-003](../profile-text-postprocessing-cost/evidence/native-reference.md)
показало 92–95% времени на повторную генерацию текста, поэтому сравниваем короткие
точечные поправки с существующим cleanup, сохраняя исходник и проверки LLM-003.

## What Changes

- Добавить явно экспериментальный режим только инженерного text profiler: локальный
  Ollama получает JSON schema и выдаёт небольшие привязанные поправки before/after.
- Сравнить также более простой ответ «исходный номер + изменённая строка»: привязку
  к before строит код. Первый anchors pilot оказался недостаточно полезным/стабильным;
  результаты не отбрасываются и не выдаются за успешный переход.
- Консервативный validator допускает только сохранение содержательных слов с
  пунктуацией/регистром и удалением узкого списка вокальных пауз. Числа, отрицания,
  IDs и точное совпадение before проверяются отдельно; ошибочная строка остаётся
  исходной. Лексическая переформулировка не применяется. Это более узкий кандидат,
  не эквивалент всей функциональности текущего cleanup/refine.
- Проверить parser/validator на намеренно опасных ответах, затем настоящие 9B и
  установленную 3B на контролируемом corpus с ожидаемыми результатами и no-op cases.
  Успешная схема/быстрый пустой ответ не засчитываются за качество.
- При пригодности короткого теста измерить полный публичный двухчасовой cleanup,
  сохранить counters и ограничения. Обычный worker/UI/TUI не переключать на кандидат.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Только инженерный эксперимент, `skip_specs: true`. PIPE-006/LLM-003 и
правило STT + optional summary сохраняются. Для принятия нового пользовательского
поведения нужны delta и отдельное подтверждение качества.

## Impact

Benchmark proxy/text profiler, model-free adversarial tests, synthetic corpus,
native evidence и руководство. Default proxy сохраняет exact forwarding; production
LLM/worker/prompts не меняются. Пользовательские `.env`, архив и демон не затрагиваются.
