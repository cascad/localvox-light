# Proposal

## Why

Владелец сообщил, что Ctrl+V закрывает TUI в отдельном WezTerm на Windows; раньше
вместо вставки открывалась палитра с импортом URL. Передача pasted characters в
command handler нарушает TERM-007 и безопасный ввод: двоеточие/буквы ссылки могут
открыть палитру/вызвать выход. Нативный путь crossterm Windows не даёт Event::Paste.

## What Changes

- По уточнению владельца 2026-11-11 поддерживать общие терминальные протоколы на
  Windows/macOS/Linux, без ветвления по имени эмулятора; WezTerm — воспроизведение,
  а не граница поддержки. Воспроизвести native paste path на временном ConPTY,
  проверить границы вставки до keyboard commands без эвристики скорости набора.
- Исправить чтение вставки Windows; URL вне формы предлагает явный импорт,
  вставка в форму остаётся исходным текстом. Само Ctrl+V не запускает обработку.
- Проверить URL с q/двоеточием/переносами, фильтр, документ, форму, RU/EN,
  supplementary Unicode, выход и восстановление режима. Реальные платформы и
  эмуляторы отмечать проверенными только после соответствующего прогона.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `archive-playback`: безопасная вставка и явный URL action в TUI, ARCH-014.

## Impact

Терминальный ввод/формы/тесты; точный input adapter выбирается после native probe.
Рабочий daemon/архив/буфер обмена владельца не используются для тестирования.
Сохранение пользовательских настроек WezTerm не меняется.
