# Spec Delta

## ADDED Requirements

### Requirement: ARCH-020 Управление выбранной записью лога в TUI

В журнале обработки и консоли ошибок TUI SHALL поддерживать j/k для перемещения
между выбранными записями, l/h для раскрытия/сворачивания и y для копирования
выбранной записи с её контекстом. Раскрытие/сворачивание SHALL быть идемпотентным.
Стрелки и Enter сохраняются; Ctrl+Y в консоли SHALL копировать весь лог.
В активном текстовом поле эти символы SHALL оставаться текстовым вводом.

Код: [input](../../../../../crates/localvox-light-terminal/src/app/input.rs),
[console](../../../../../crates/localvox-light-terminal/src/app/diagnostics.rs),
[journal](../../../../../crates/localvox-light-terminal/src/journal.rs).

#### Scenario: Консоль ошибок
- **WHEN** пользователь выбирает вторую ошибку через j/k, нажимает l, затем y
- **THEN** раскрывается вторая ошибка и копируется только она с сессией/этапом,
  повторный l не сворачивает её, h сворачивает.

#### Scenario: Журнал обработки
- **WHEN** выбрана группа операций во вкладке «Ход», пользователь нажимает h/l/y
- **THEN** меняется раскрытие выбранной группы и копируется её читаемый текст;
  остальная история не попадает в буфер.

#### Scenario: Текстовый фильтр
- **WHEN** пользователь редактирует фильтр журнала
- **THEN** j/k/h/l/y вводят символы, а не перемещают выбор или копируют лог.
