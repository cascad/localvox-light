# Design

## Context

См. proposal.md. Есть сохранённые 704 строки Podlodka #109 и release profiler;
исправление сохранности принято в `2fc1a62`, но последний полный прогон был до него.

## Goals / Non-Goals

Измерить текущий release cleanup и проверить новые сохранённые результаты.
Сравнение смысловой точности по аудио, Mac/CPU, summary и смена defaults вне этапа.

## Decisions

- Собрать release worker/profiler с `--locked --offline -j 2`, фиксировать SHA до
  и после серии. Использовать прежний cleanup-only manifest/source SHA, отдельный
  новый output для каждого запуска. Архив/демон не участвуют.
- Порядок Gemma → Qwen → Gemma → Qwen, один repeat на output, timeout 900 s.
  Context 4096/temperature 0.2/think=false сохраняются обычным worker.
  Никаких принудительных выгрузок внешней Ollama. Wall и native generation отдельно;
  сравнение с прежними числами описательное, фон/порядок не контролируются полностью.
- Повторно проверять input bytes, source version, границы edits, receipts и переносы
  соседних слов существующим evaluator. Проверить прежние рискованные индексы Gemma
  439 и Qwen 95/256/267/666/686/702 во всех новых результатах.
- Для agent-review зафиксировать до прогона: прежние 51 reviewed строки (по модели),
  плюс 8 равномерных позиций среди принятых edits каждого нового запуска. Объединять
  дубли, читать source/actual с соседними исходными репликами. Категории: unchanged,
  context_supported, meaning_risk, style_review, audio_required, cross_line.
  Это целевая выборка, не общий процент точности. В Git только индексы/hashes/оценки,
  текст публичного разговора остаётся в target.
- Если обнаружится новый отказ, записать воспроизведение; не ослаблять guard/oracle
  и не объявлять модель принятой ради завершения измерения.

## Risks / Trade-offs

Консервативный fallback снижает полезность → считать edits отдельно от качества;
новый ответ не обязан повторять старый. Два повтора не доказывают статистическую
надёжность. GPU/соседние приложения → последовательные запуски, честные условия,
не приписывать все ожидания модели и не обещать Mac SLA.
