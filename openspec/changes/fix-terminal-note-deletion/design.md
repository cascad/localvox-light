# Design

## Context

См. proposal.md. В «Архиве» выбор списка и открытый документ независимы;
DeleteSession ошибочно использовал только current. Левая панель «Заметок» содержит слоты, правая — заметки.
Команда хранит captured slot/raw/source в подтверждении; HTTP DELETE возвращает
raw в deleted. После удаления item не ограничен новым размером, а поздний Notes
ответ с большим request ID может вернуть старый список после acknowledgement.
HTTP удаление уже выполняется в I/O worker с timeout, не в UI потоке.

## Goals / Non-Goals

Контекстное удаление выбранной записи/заметки с проверяемым подтверждением и отзывчивым
ожиданием. Удаление слота, новая файловая система заметок и недоказанные Mac-specific
обходы не входят в работу.

## Decisions

- d/Delete в Archive/Notes вне ввода. В Archive list target берётся из
  visible_sessions[selected], в деталях — из current. Заголовок и task используют
  одну captured identity; открытый документ не переключается ради подтверждения.
  При смене слота клавишами курсор заметки
  сбрасывается; команда проверяет readable/error/наличие заметки и задаёт фокус
  выбранной заметке. Подтверждение s сохраняет исходные slot/raw/source.
- Заголовок — ограниченный однострочный preview, полный текст не попадает в
  геометрию окна. Полная identity остаётся в task.
- Успешный acknowledgement удаляет точную identity, ограничивает курсор и
  увеличивает существующий epoch. Нижняя граница epoch соответствующего ресурса
  отсекает даже глобальные Sessions/Queue/Jobs snapshots, включая
  стартовавшие во время mutation. Новые чтения возобновляются штатным refresh.
  Client tombstones и произвольные задержки не нужны.
- При неверном acknowledgement удаление не объявляется успешным. При ошибке
  исходные данные сохраняются. Нет синхронного ожидания HTTP в обработчике клавиш.
- Проверить delayed DELETE отдельным HTTP fixture и UI/control task, затем
  настоящий PTY/ConPTY d→Esc, палитра→s→обновление. Тот же PTY сценарий включён
  в обе native macOS сборки CI; до фактического запуска это не свидетельство Mac.
  Файловое удаление — через production HTTP API
  в существующем notes roundtrip тесте, с сохранением соседней заметки.

## Risks / Trade-offs

Mac: владелец подтвердил зависание при открытии удаления небольшой записи,
до подтверждения. Это исключает удаление файлов и большой текст заметки как
подтверждённые причины; аппаратный повтор остаётся отдельным свидетельством.
Не трогать его архив/vault.
