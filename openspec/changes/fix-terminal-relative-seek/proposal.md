# Proposal

## Why

Повторные Alt+стрелки используют запаздывающую позицию TUI и отправляют один и тот
же absolute seek вместо накопления шагов. Владелец также запросил Enter наряду с s
в подтверждении полного выхода, без подтверждения удержанием клавиши.

## What Changes

- Передавать относительное перемещение владельцу плеера, сохраняя паузу, границы
  доступного аудио и смену записи; не изображать отправленную позицию выполненной.
- Разрешить обычный Enter только в диалоге полного выхода; s/ы и совместимые
  Ctrl-сочетания сохраняются, Repeat/Paste не отправляют shutdown.
- Проверить последовательность настоящих hotkey → worker → mpv при задержанной
  телеметрии; обновить подсказки, справочник и локальный комплект.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `archive-playback`: относительная перемотка TUI при нескольких нажатиях.
- `runtime-settings`: Enter в явном подтверждении полного выхода.

## Impact

TUI app/player/input/render, native mpv и keyboard tests, user-guide, evidence.
Демон, архив, зависимости моделей и браузерный плеер не меняются.
