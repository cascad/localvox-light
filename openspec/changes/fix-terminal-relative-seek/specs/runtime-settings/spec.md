# Spec Delta

## MODIFIED Requirements

Уточнение RUN-006/007 из `unify-client-confirmations` по новому поручению владельца;
эти delta ещё не синхронизированы в main.

### Requirement: RUN-006 Явное завершение LocalVox

TUI SHALL иметь отдельное действие «Завершить LocalVox». Обычный выход SHALL
закрывать только клиент. Полный выход SHALL требовать диалог с адресом демона и
предупреждением об остановке записи и восстановлении очереди после запуска.
Подтверждение SHALL приниматься по Enter, s/ы, Ctrl+S или Ctrl+Enter без ввода текста;
Esc SHALL отменять его. Paste, Repeat и Tab SHALL не отправлять stop. Демон SHALL
использовать штатную ограниченную остановку компонентов; auth/origin/host/лимиты
API сохраняются. После начала остановки новые mutations отклоняются. Клиент SHALL
ждать успешного cleanup; ошибка/timeout не являются успехом и не запускают
автоматический повтор/новый демон.

Код: [TUI input](../../../../../crates/localvox-light-terminal/src/app/input.rs).

#### Scenario: Явное подтверждение
- **WHEN** пользователь отдельно нажал Enter либо s в открытом диалоге полного выхода
- **THEN** отправляется один shutdown, клиент ждёт результата; Esc вместо подтверждения не отправляет запрос.

#### Scenario: Удержание клавиши открытия
- **WHEN** Enter открыл подтверждение через палитру, после чего пришли Repeat или Paste
- **THEN** shutdown не отправляется до отдельного нового нажатия подтверждения.

### Requirement: RUN-007 Единые подтверждения действий

TUI SHALL показывать компактное подтверждение с действием/целью без требования
вводить ДА/имя/другой текст для settings, discard, delete, recook, cancel и shutdown.
s SHALL подтверждать только такой диалог; Ctrl+S/Ctrl+Enter совместимы, Esc отменяет.
Текстовые формы SHALL сохранять ввод s. Shift+S открытия, paste и Repeat SHALL не
подтверждать. Обычный Enter SHALL подтверждать только полный выход; остальные
подтверждения по нему не отправляются. Цель SHALL фиксироваться при открытии,
pending SHALL не дублироваться. UI SHALL также не требовать печатать слова
подтверждения. Клиенты SHALL сохранять обязательный API confirmation payload
и проверки владения.

Код: [forms](../../../../../crates/localvox-light-terminal/src/app/forms.rs).

#### Scenario: Сохранение настроек
- **WHEN** s открыл подтверждение сохранения, а затем пользователь отдельно нажал s
- **THEN** один запрос содержит показанный набор изменений; первое нажатие только открывает окно, событие Repeat не отправляет его.

#### Scenario: Исходная цель и инертная вставка
- **WHEN** после открытия подтверждения сменился выбранный элемент или пришёл paste/Repeat
- **THEN** действие не подтверждается этими событиями; явный s относится к исходной цели.

#### Scenario: Enter вне полного выхода
- **WHEN** Enter нажат в подтверждении удаления, сохранения или переварки
- **THEN** действие не отправляется; s и Esc продолжают работать по общим правилам.
