# Spec Delta

## MODIFIED Requirements

### Requirement: ARCH-002 Один плеер и граница реплики

UI SHALL использовать один audio-элемент: клик по строке задаёт start и until,
останавливается у конца реплики; клик по волне/обычный Play снимает ограничение
until. Повторный клик по той же строке различается nonce. Диапазон seek ограничивается
длительностью. TUI SHALL перематывать относительно позиции владельца плеера:
Alt+←/→ дают шаг −/+15 с, стрелки в фокусе плеера −/+5 с. Последовательные нажатия
SHALL накапливаться при задержанной телеметрии, сохранять паузу и не менять другую
запись. Перемотка SHALL снимать границу фрагмента, оставаясь в доступном аудио.

Код: [UI](../../../../../ui/src/Player.tsx),
[TUI](../../../../../crates/localvox-light-terminal/src/player.rs).

#### Scenario: Та же реплика дважды
- **WHEN** клик повторён на том же времени
- **THEN** nonce вызывает повторное воспроизведение.

#### Scenario: Продолжение
- **WHEN** после клипа нажата обычная Play
- **THEN** until сбрасывается, воспроизведение продолжается.

#### Scenario: Несколько перемоток до обновления позиции
- **WHEN** на паузе с позиции 0 TUI получил три Alt+→ до следующего отчёта плеера
- **THEN** позиция становится 45 с в пределах доступного аудио, пауза сохраняется;
  три Alt+← возвращают к 0 с, а не повторяют один абсолютный seek.

#### Scenario: Смешанные шаги и новая запись
- **WHEN** пользователь меняет направление или перематывает выбранную новую запись
- **THEN** шаги применяются в порядке ввода к нужной записи, не к старому времени
  другой записи; начало и конец аудио ограничивают результат.
