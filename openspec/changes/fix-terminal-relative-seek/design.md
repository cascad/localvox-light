# Design

## Context

App::nudge переводит относительный шаг в absolute target по последнему PlaybackState.
Worker сообщает состояние асинхронно: серия клавиш до ответа превращается в 15/15/15.
Поток плеера владеет реальной позицией и очередью команд. Подтверждения
имеют общий фильтр Press; ранний constrained-form Enter нельзя использовать для shutdown.

## Goals / Non-Goals

Накопление шагов без фиктивной оптимистичной позиции TUI. Сохранить границы аудио,
pause/fragment semantics и захват ввода форм. Enter добавляется только к shutdown.
Демон, UI, форматы архивов и модели не меняются.

## Decisions

- Отдельная команда relative seek передаёт session/delta владельцу mpv;
  абсолютные Home/End/переход ко времени остаются absolute. Текстовый ввод инертен.
- Поток плеера хранит принятую цель перехода отдельно от фактической позиции;
  первый относительный шаг берёт позицию mpv, следующие накапливаются от цели.
  Команды mpv остаются absolute+exact: native relative+exact на паузе накапливал
  погрешность аудиобуфера (три шага дали 44.449 вместо 45 секунд).
  Цель сбрасывается при Load/Stop/Toggle/ошибке и когда воспроизведение догоняет её.
  Нет таймеров сглаживания или подмены отображаемого времени заданной целью.
  Сохраняются wait-ready, снятие границы фрагмента и существующий load при смене записи.
- Enter для shutdown проходит через тот же Press-only фильтр, что s, а не через
  общий accepts_enter для текстовых форм. Подсказка зависит от типа подтверждения.
- Native regression: App → Player → настоящий mpv/null audio, намеренно не отдавать
  телеметрию App между несколькими клавишами; дополнить state/PTY/render checks.

## Risks / Trade-offs

mpv может объединять быстрые seeks: native burst test проверяет фактический итог,
не только JSON-команду. Clock buffer проверяется прежним допуском 250 ms;
это не изменение sample boundaries записи или точного endpoint фрагмента.

## Migration Plan

Пересобрать TUI и локальный полный комплект. Работающий пользовательский плеер
не используется для тестов; Windows подтверждается фактически, Mac/Linux not-run.
