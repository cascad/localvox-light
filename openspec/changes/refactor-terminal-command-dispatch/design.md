# Design

## Context

См. [proposal](proposal.md). app/forms.rs объединяет редактор и 38 веток command(usize);
App::commands каждый раз выделяет Vec подписей. app.rs/runtime.rs вызывают команды
по номеру, render.rs рисует независимый список. Текущие tests также используют номера.

## Goals / Non-Goals

Сохранить все действия и отображение, убрав связь между номером меню и смыслом команды.
Не менять протокол HTTP, форму payload, подтверждения удаления/повторов, управление
записью, плеер или общий контракт ошибок. Не закрывать аппаратную приёмку.

## Decisions

- Enum Action именует операции; App::command принимает Action вместо usize.
  Это исключает случайную передачу номера из другого меню. Константы usize оставили
  бы саму неоднозначность и не позволили бы проверять типы на границах вызова.
- Статический каталог связывает Action с подписью в прежнем порядке. Индекс остаётся
  только курсором палитры; Enter сначала получает действие выбранной строки.
  Каталог не выделяет Vec при вводе/рендеринге.
- Диспетчер и каталог размещаются в app/commands.rs. Редактор, отправка форм,
  очередь эффектов и восстановление черновиков остаются в app/forms.rs.
- Сохраняются все проверки контекста перед действием, отдельные подтверждения,
  снимок сессии формы и приоритет формы над буквенными хоткеями.

## Risks / Trade-offs

- Ошибка переноса ветки → механическое сопоставление всех прежних индексов,
  полный пакет terminal, проверки через настоящий ввод палитры и runtime.
- Потеря записи/подтверждения → отдельные проверки F8/F9 из формы и опасных действий
  через палитру; ConPTY подтверждает сохранение серверной записи после выхода.
- Изменение визуала → прежние snapshots не обновляются; любое расхождение исследуется.

## Migration Plan

Перенос кода, замена точек вызова и существующих тестов, затем unit/snapshot/ConPTY
и совместная проверка настоящих API/UI/TUI. Сборка только клиента; демон владельца
и архив не трогаются. Откат — исходный commit пользователя, миграции данных нет.
