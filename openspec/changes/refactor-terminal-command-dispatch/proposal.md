# Именованные действия терминального клиента

## Why

После добавления хоткеев чтения и выхода продолжаем запрошенную владельцем очистку
кодовой базы. Сейчас 38 подписей палитры и обработчик действий связаны числовыми
индексами: например, F8 вызывает command(2), y — command(22). Перестановка или
вставка пункта легко нарушит управление, хотя код продолжит компилироваться.
Подтверждённого сбоя из-за перестановки сейчас нет: это устранение хрупкой связи.

## What Changes

- Ввести именованные действия и единый статический каталог палитры.
- Перевести палитру, хоткеи, runtime F8/F9 и тесты на эти действия.
- Отделить диспетчер команд от редактора/валидации форм.
- Проверить маршруты палитры и клавиатуры, сохранение подтверждений опасных действий,
  ввод в формах и существующие snapshots/ConPTY без изменения baseline.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Чистый рефакторинг, `skip_specs: true`. Контракты ARCH-001–003 и TERM-007
из активного add-technical-journal-workspace сохраняются, внешний API и UI не меняются.

## Impact

Только localvox-light-terminal, его тесты и evidence. Порядок/подписи палитры,
хоткеи, подтверждения, payload, выбор текущей записи и поведение форм сохраняются.
Нет новых зависимостей, обращения к моделям или изменений пользовательского архива.
