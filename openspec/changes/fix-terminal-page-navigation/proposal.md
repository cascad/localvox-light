# Proposal

## Why

По замечанию владельца Page Up/Down должны листать целые видимые страницы. Сейчас
документ перемещается на 10 строк независимо от окна, список не перелистывается;
расчёт scroll не вычитает заголовки документа из доступной высоты.

## What Changes

- Привязать размер страницы к реально отрисованной области документа/списка.
- Page Up/Down листают документ либо видимые записи в зависимости от фокуса;
  список сохраняет относительное положение выбора, не открывает запись сам.
- Сохранить фильтр, отсутствие автопрокрутки при чтении, границы и работу после resize.
- Обновить короткий чек-лист проверки и справочник.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `archive-playback`: ARCH-013, постраничная навигация TUI.

## Impact

TUI layout/scroll/input, tests, производные руководства. Сервер, UI, аудио и модели
не меняются; рабочий daemon и архив не затрагиваются.
