# Proposal

## Why

Владелец видит медленную загрузку Vosk и только счётчик времени вместо объёма,
скорости и остатка. Локальный новый vox также не был установлен поверх публичной
версии; этот разрыв воспроизведён и текущая F:\lv обновлена проверенным кандидатом.

## What Changes

- Один native HTTP downloader для моделей из мастера на Windows/macOS/Linux,
  один renderer: байты/общий объём, процент, скорость, ETA; неизвестный размер и
  распаковка показывают spinner. Логи не превращаются в поток повторов.
- Неизменённая Vosk ru 0.42 скачивается с проверенного быстрого закреплённого
  зеркала, с полным SHA-256 и официальным резервным источником тех же байтов.
- Большой ZIP и распаковка размещаются на диске выбранной модели, не в системном TEMP.
- Существующие модели/настройки сохраняются, проверки без изменений не скачивают.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `installation-models`: видимая загрузка моделей, закреплённые источники, целостность.

## Impact

setup-ui activity/progress, native installer download mode, executor, PS/Bash fetch,
models.json, справочник и проверка доставки. Public release/push требует отдельного
поручения по AGENTS.md; подготовка и проверка локальной установки входят в работу.
