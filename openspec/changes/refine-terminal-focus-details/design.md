# Design

## Context

См. proposal. Общий panel уже рисует минимальные TOP/LEFT границы. Цвет command
сейчас одновременно обозначает команду и фокус; заголовок активной панели использует
ту же label роль, что неактивные. Смысловые роли ARCH-015 сохраняются.

## Goals / Non-Goals

**Goals:** явный фокус и спокойная деталировка как в показанном референсе.

**Non-Goals:** перестановка/добавление панелей, git, новые команды или ANSI по emulator name.

## Decisions

- Добавить Theme.focus отдельно от command/value. Focus окрашивает активную рамку
  и технический title; реальные названия документов сохраняют ink. Неактивные рамки
  приглушены. Overlay обозначает активность той же ролью.
- Тёмная палитра немного смещается в navy, выделение — в мягкий тёплый оттенок;
  светлая получает соответствующий тёплый акцент. Никакой яркой заливки всего окна.
- Геометрия/текст snapshots должны остаться побайтно прежними; меняются стили.
  16 цветов используют штатные ANSI роли, mono сохраняет маркер/начертание.

## Risks / Trade-offs

- Фокус путается со значением/ошибкой → отдельная роль, actual buffer tests и прежние
  семантические error/success цвета; readable contrast text/labels/value/focus ≥4.5.
- Незаметное изменение отступов/переносов → сравнение каждого snapshot content и area,
  повтор INSTA_UPDATE=no. Ручная эстетическая приёмка владельца остаётся not-run.
