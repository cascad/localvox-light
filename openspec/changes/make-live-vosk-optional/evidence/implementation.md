# Проверка — 2026-11-22

Реализованы LIVE-002 и SETUP-001/003 в delta этого change по поручению владельца.
Main specs пока не синхронизированы; исторические результаты не заменяются.

## Поведение

- `.env.defaults`: `LOCALVOX_LIGHT_LIVE_ASR=off`. Общий каталог отдаёт переключатель
  UI/TUI с применением после перезапуска; он включён в обычный список настроек TUI.
- Мастер: обязательная модель GigaAM; Vosk — отдельная галочка Voice. План сохраняет
  on/off после успешных действий, готовые пути/веса повторно используются. Снятие
  галочки не удаляет модель. При последующем изменении настройки сохранённый флаг
  определяет начальную галочку мастера.
- Engine без выбранного/имеющегося Vosk не запускает loader/pool/recovery, не
  удаляет старые live `.part` и не создаёт fast-lane сегменты. ChunkLane, запись
  и ранняя обработка GigaAM независимы. Устаревший маркер голосового модуля очищается.
- `/api/record` добавляет совместимое поле `model_notices`. Проверки файлов без
  inference/сетевых запросов используют разрешение путей и правила doctor.
  Vosk объясняется в «Заметках»/настройках, GigaAM — в архиве/очереди, без модальных
  окон и повторных сообщений в консоли. Копирование документа не включает подсказки.
- `vox setup` передаёт текущую папку и терминал соседнему installer до подключения
  TUI к API. `--check` сохраняет код doctor 0/1/2. Изменения требуют завершить
  работающий LocalVox; мастер сам не останавливает запись и не запускает daemon.

## Границы

- Нативные Mac/Linux, качество физического микрофона/loopback и новый inference
  Vosk/GigaAM на длинной записи здесь не проверялись. Проверка наличия файлов не
  выдаётся за загруженную исправную модель или качество распознавания.
- Новый публичный release не создан; команда из GitHub не обновлена этим локальным
  коммитом. `F:\lv` к завершению работы отсутствует, существующая установка не патчилась.
- Перенос необязательного архива Vosk на собственное зеркало и единая полоса
  bytes/speed/ETA для скачивания моделей остаются отдельной работой. Здесь изменён
  обязательный комплект, не URL или транспорт загрузчика.
