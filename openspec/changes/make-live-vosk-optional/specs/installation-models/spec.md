# Spec Delta

## MODIFIED Requirements

### Requirement: SETUP-001 Манифест загрузки

fetch-models SHALL использовать scripts/models.json, поддерживать выбор компонентов и required-only; Check проверяет наличие без загрузки. В каталоге required — GigaAM, optional — Vosk/diarize/NER; отсутствие optional снижает возможности соответствующего этапа. Список моделей и размеры в README не задают правила загрузчика. Мастер SHALL предлагать Vosk отдельной выключенной по умолчанию галочкой для голосовых команд и мгновенного черновика. Выбор SHALL сохранять режим работы; снятие галочки не удаляет уже скачанные модели.

Код: [manifest](../../../../../scripts/models.json), [installer](../../../../../crates/localvox-light/src/setup/install.rs).

#### Scenario: Required only

- **WHEN** запрошен минимальный комплект
- **THEN** скачивается GigaAM, optional-компоненты пропускаются.

#### Scenario: Check

- **WHEN** включён режим проверки
- **THEN** веса не скачиваются.

#### Scenario: Обычная установка

- **WHEN** устанавливается рекомендованный комплект на чистой машине
- **THEN** Vosk не скачивается и живое распознавание выключено; запись, импорт и ранняя расшифровка GigaAM доступны.

#### Scenario: Включение голосового управления

- **WHEN** пользователь выбирает голосовые команды и мгновенный черновик
- **THEN** мастер использует исправную готовую модель Vosk либо скачивает её и сохраняет включённый режим.

#### Scenario: Доустановка после первого запуска

- **WHEN** пользователь запускает `vox setup` и добавляет ранее не выбранный Vosk
- **THEN** открывается тот же мастер для текущей установки, готовые компоненты используются повторно, скачиваются только недостающие веса, а включённый режим сохраняется после успешной установки. Сам запуск мастера не запускает демон и не останавливает запись; перед изменениями требуется завершить работающий LocalVox.

#### Scenario: Проверка через короткую команду

- **WHEN** пользователь запускает `vox setup --check`
- **THEN** выполняется диагностика текущей установки без запуска TUI, демона, inference или скачиваний.

### Requirement: SETUP-003 Doctor и границы проверки

Doctor SHALL собирать Layout, проверять доступные компоненты и выдавать Finding OK/Warn/Fail с пояснением и fix; exit code 0/1/2 различает полноту работоспособности. Выключенный Vosk SHALL отмечаться как выключенная опция без ошибки о недостающей модели; явно включённый Vosk с отсутствующей или неполной моделью SHALL считаться неисправным. Это диагностика наличия/доступности, не полный прогон ASR и не измерение качества/скорости.

Код: [doctor](../../../../../crates/localvox-light-core/src/doctor.rs).

#### Scenario: Нет worker

- **WHEN** соседний localvox-process отсутствует
- **THEN** doctor сообщает недоступную фоновую обработку и способ исправления.

#### Scenario: Vosk выключен

- **WHEN** голосовое управление выключено и модель Vosk отсутствует
- **THEN** doctor сообщает о выключенной опции, не о сломанной установке.

#### Scenario: Vosk включён без модели

- **WHEN** живое распознавание включено, но модель неполна
- **THEN** doctor сообщает ошибку и способ доустановки модели.

#### Scenario: Нет модели архивной расшифровки

- **WHEN** пользователь открывает архив или очередь, а GigaAM отсутствует или неполон
- **THEN** UI/TUI показывают спокойную подсказку о невозможности новой расшифровки и установке модели; готовые результаты остаются доступны, модальное окно и повторяющиеся уведомления не открываются.
