# Proposal

## Why

У согласованного выпуска v0.2.12 остановлена публикация: Windows tar не смог
распаковать проверенный ZIP в Unicode-путь на английском runner. Расширенный
локальный fixture воспроизвёл отказ на Windows с другой ANSI code page.

## What Changes

- Штатный tar получает ASCII-имя архива; рабочий каталог передаётся через
  Unicode API запуска процесса, без преобразования полного пути в ANSI argv.
- Один fixture проверяет Unicode вне CP1251/CP1252, пробелы и обе ветки fresh/cache;
  ошибки дочерней программы сохраняются независимо от кодировки её диагностики.
- Общий HTTP-сценарий проверяет одинаковые сообщения авторизации отдельно в
  панели архива и в настройках, после обновления обоих клиентов.
- Следующий patch 0.2.13, без изменения тега v0.2.12 или прежних результатов.
- Delivery и настоящий mpv проверяются локально; затем проверяется фактический
  hosted run, публикация и пять архивов/четыре install-скрипта.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Исправление dev/CI tooling и версия, без изменения поведения продукта;
`skip_specs: true`.

## Impact

`setup-mpv.mjs`, delivery regression, версии Cargo/UI/Tauri и release evidence.
Рабочая установка, пользовательские модели и архив не меняются.
