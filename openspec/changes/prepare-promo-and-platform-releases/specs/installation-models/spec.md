## ADDED Requirements

### Requirement: SETUP-004 Полный платформенный комплект

Release package SHALL содержать согласованные daemon со встроенным web UI, worker,
TUI, требуемые нативные библиотеки, предустановки и сопроводительные лицензии для
Windows x64 и macOS Intel/Apple Silicon. Установка SHALL выбирать полный архив
своей платформы из release либо принимать явно указанный локальный архив, сохранять
существующую `.env` и завершаться ошибкой при отсутствии обязательного компонента
или отказе загрузки. Сборка и проверка пакета не заменяют приёмку аудиоустройств.

#### Scenario: Release installation

- **WHEN** пользователь запускает установщик для доступного полного release
- **THEN** устанавливаются daemon, worker, TUI и нативные зависимости одной версии для его платформы; существующие настройки сохраняются.

#### Scenario: Archive from Actions

- **WHEN** пользователь передаёт установщику локальный платформенный архив из CI
- **THEN** применяется тот же путь проверки состава и установки без повторной загрузки бинарников.

#### Scenario: Incomplete or unavailable release

- **WHEN** release содержит только старый отдельный бинарник, не содержит нужной платформы или загрузка/обязательный компонент недоступны
- **THEN** установка явно завершается ошибкой, не выдавая частичный комплект за готовый продукт.

#### Scenario: Packaged startup

- **WHEN** пакет распакован без dev-окружения репозитория
- **THEN** daemon и worker запускают диагностические команды, TUI сообщает версию, а web UI входит в пакет; аппаратная запись на Mac проверяется отдельно владельцем.
