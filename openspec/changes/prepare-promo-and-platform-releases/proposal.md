# Proposal

## Why

Владелец поручил подготовить реальные скриншоты/GIF UI и TUI, вынести установку
сразу после описания в README и восстановить доставку полного продукта на Windows
и macOS. Проверку демона на своём Mac владелец выполняет сам.

## What Changes

- Воспроизводимая съёмка настоящих UI и TUI на вымышленных демонстрационных данных;
  PNG/GIF для README и отдельная компактная галерея для промо.
- Полный переносимый release-пакет: daemon со встроенным UI, worker, TUI, desktop
  там, где он собирается, нативные библиотеки, preset и установочные scripts.
- CI для Windows x64 и macOS Intel/Apple Silicon; существующий Linux сохраняется.
  Проверка пакета и smoke установки выполняются до публикации.
- Скрипты установки выбирают точный пакет своей платформы, сохраняют `.env`,
  поддерживают архив из Actions и не сообщают успех при неполном комплекте.
- Короткая инструкция запуска/установки в начале README. Mac daemon/capture,
  permissions и настоящий звук явно остаются ручной приёмкой владельца.

## Capabilities

### New Capabilities

Нет новых runtime возможностей обработки/интерфейса.

### Modified Capabilities

- `installation-models`: SETUP-004 — полный платформенный пакет и согласованная
  установка; SETUP-002/003 сохраняются без ослабления.

## Impact

`.github/workflows`, install/package scripts, README/docs, promo fixtures/capture
tools/assets; только исправления native dependency staging при необходимости.
Архив, настройки пользователя и работающий демон для съёмки не используются.
Push, создание tag и публикация release не входят в полномочия этой работы.

Наблюдения 2026-11-11: последний опубликованный v0.1.5 содержит отдельные старые
EXE вместо полного архива; текущий pack не копирует DLL/dylib, guard UI подавляет
ошибку через `|| true`, push рабочей ветки не запускает workflows. Это выводы
чтения, не результат нового hosted CI. Проверка C: — отдельная уборка только
подтверждённых ненужных артефактов агента.
