# Сохранять заметку до доставки

## Why

Сверка RV-007 подтвердила несоответствие принятому [DEC-008](../review-code-inventory/proposal.md#dec-008):
voice worker напрямую вызывает `Slot::write_note`; `.voice.json` хранит только последнее
состояние, а отдельного журнала заметок/доставок нет. Brain заранее выдаёт действия
успешного подтверждения, которые остаются после ошибки назначения. Две заметки
с одинаковым slug в одну секунду могут перезаписать один файл.

Основание: BL-021; [evidence](../../evidence/implementation-review-2026-09-27.md).
Расхождение с NOTE-006/VOICE-004 подтверждено кодом; изолированный mock 2026-09-27
проверил отказ, timeout, успешный повтор и дубль при lost-ack. Настоящие назначения
не вызывались. Принятие baseline не означает реализацию local-first.

## What Changes

- До обращения к назначению атомарно сохранять локальную заметку с уникальным ID.
- Хранить статус каждой доставки отдельно от сохранённого текста; ошибка и
  неопределённый исход внешнего вызова не теряют текст и не означают «доставлено».
- Подтверждать результат по факту локального сохранения/доставки, включая TTS.
- Поддержать ограниченный повтор с восстановлением после рестарта; правила повторов
  для неоднозначного внешнего ответа и назначений без idempotency определить в design.
- Исключить перезапись соседней заметки при совпадении секунды/slug.
- Проверять отказы на временных файлах и mock MCP, без отправки в реальные назначения.

## Capabilities

### New Capabilities

Нет: используется существующее разделение заметок и интеграций.

### Modified Capabilities

- `voice-notes`: VOICE-004 подтверждает фактический результат, обработка не теряет принятую диктовку.
- `note-integrations`: локальный документ и доставка имеют отдельные состояния; коллизии и повторы не уничтожают заметки.

## Impact

Voice worker/Brain, integrations, API заметок и их UI, новый локальный формат и
восстановление delivery worker. Не обещается exactly-once для внешнего инструмента
без поддержки идемпотентности. Готовые текстовые файлы назначений не мигрируются вслепую.
Статус: proposal-only; deltas/design/tasks и реализация ещё не выполнены.
