# Proposal

## Why

BL-003 пока измеряет отдельные worker. Реальный координатор находится в бинарном модуле приложения, что мешает изолированному замеру очереди без запуска захвата устройств. Нужен общий библиотечный вход и точные события сохранённых переходов для инженерного стенда.

## What Changes

- Вывести существующий autocook через библиотеку пакета localvox-light и использовать её из main, сохранив файл/реализацию/настройки.
- Добавить необязательный bounded observer метаданных claim/принятого исхода без блокировки очереди и без содержимого транскриптов/ошибок. Обычный daemon работает без observer.
- Добавить headless queue runner в bench: только явно помеченное тестовое workspace, тот же worker и coordinator, кооперативная остановка и отчёт. Микрофон/API приложения не запускаются.
- Перенести выполнение существующих coordinator tests с main binary на lib, добавить проверки observer/защит стенда и документацию.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Это рефакторинг и измерительные инструменты без смены требований поведения продукта; skip_specs=true. PIPE-002/008/009/010/011 сохраняются, данные jobs/journal и действия UI/TUI не меняются.

## Impact

Root package lib/main, autocook optional metadata observer, bench runner, Cargo/CI и evidence. Не закрывает аппаратную приёмку, BL-002/004 или полный BL-003; не включает изменение модели/лимитов генерации.
