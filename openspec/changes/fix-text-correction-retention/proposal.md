# Proposal

## Why

RV-018/RV-019 воспроизведены native проверками: cleanup теряет смысловые оговорки и
цитируемые слова, переносит соседнюю реплику; нынешний overlap guard принимает
короткие строки без проверки и длинные с сохранённой лишь половиной слов.
Это нарушает LLM-003/PIPE-006; общий guard используется и refine, чей результат
становится рабочей версией (PIPE-005).

## What Changes

- Заменить overlap-порог локальной ограниченной проверкой соответствия исходным
  словам: исходная строка остаётся при необоснованной потере/добавлении слов.
- Защитить отрицания/оговорки, содержимое цитат/команд, числа и известные опасные
  изменения наклонения; исправления регистра, пунктуации, однозначных пауз/заиканий
  и ограниченные близкие ASR-правки должны оставаться полезными.
- Применять защиту к обычным cleanup/refine, сравнивая с фактически поданным текстом
  после детерминированного глоссария, без подключения SAGE к продукту.
- Проверить регрессии model-free, настоящий worker с fake LLM и native corpus;
  измерить сохранность и потерю полезности отдельно, не объявлять эвристику
  универсальной гарантией смысла. Исторические результаты не переписывать.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `llm-processing`: LLM-003, уточняющие сценарии сохранения исходного содержания.
- `processing-pipeline`: PIPE-005/006, отклонение опасной правки с сохранением
  версии-источника/таймингов и корректным учётом rejected.

## Impact

LLM correction guard, admission обоих построчных этапов, regression/integration
tests, OpenSpec evidence и короткое уточнение пользовательского справочника.
Без изменения ASR, summary, default модели, API/UI/TUI действий и рабочего архива.
