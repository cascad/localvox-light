# RV-018 / RV-019 — 2026-11-02

Исправлены воспроизведённые отказы admission в обычных cleanup/refine. Новая
детерминированная проверка не является общей приёмкой качества моделей. Рабочий
демон не обновлялся, старый архив/результаты не переписывались, SAGE не подключён
к продукту. Default STT + optional summary остался прежним.

## До исправления

База `ea8849b`: короткая строка <4 слов принималась без проверки, длинной хватало
половины исходных слов. [Первый native corpus](../../experiment-guarded-sparse-text-edits/evidence/implementation.md),
[расширенная проверка](../../evaluate-local-cleanup-quality/evidence/results.md)
и [отбор компактных моделей](../../screen-portable-cleanup-models/evidence/results.md)
воспроизвели потери «почти»/«пока», буквального «эээ», сравнительного «короче»,
смену повеления на прошедшее время и перенос соседних реплик.

Новый regression test
`pipeline::tests::correction_retains_qualifiers_literals_mood_and_line_ownership`
запущен до реализации: exit 101, 1 failed; первый отказ — «Проект почти готов» →
«Проект готов». Наличие теста отдельно от фактического запуска не засчитывалось.

## Реализация

- [Общий guard](../../../../crates/localvox-light-llm/src/correction_guard.rs):
  ограниченное соответствие слов, защита оговорок/отрицаний, цитируемого содержания,
  технических символов/команд/чисел и известных опасных смен наклонения.
- [Оба admission пути](../../../../crates/localvox-light-llm/src/pipeline.rs):
  отказ сохраняет исходную строку. Cleanup сравнивает с текстом после глоссария,
  который действительно отправлялся модели. Детерминированный канон не становится
  ложной «галлюцинацией», первичная версия не изменяется.
- Номер с несколькими ответами не выбирается по last-wins: пустой маркер отказа
  проходит в admission, строка сохраняется и учитывается rejected, а не omitted.
- Содержательная вставка из соседней реплики не имеет пути в новом сопоставлении.
  Регистр/пунктуация, ограниченные близкие ASR-поправки, пробелы и однозначные
  вокальные паузы/заикания принимаются. Для длинных/неоднозначных поправок есть
  ограничение работы и быстрый путь неизменённых слов.
- Сводные omitted/rejected видны в обычном логе. Детали отказов — debug с этапом,
  временем строки/причиной, без печати двух полных текстов на каждый отказ.
  Дополнительных LLM/NER вызовов нет.

guard. Это сохранённые результаты, **не новые native вызовы**. Для моделей сравнивается
тот же source/candidate; SAGE остаётся отдельной raw категорией без worker acceptance.

- На старом 72-case Gemma после фильтра — 72/72 во всех повторах, useful 24/24
  сохранены. Qwen 4B сохраняет исходные 72/72 и 24/24.
- Все 3 склейки Granite 8B из boundary corpus отклонены.
- Старые Qwen 4B строки 95/256/267/666 с соседним содержимым, рискованные 686/702
  и Gemma 439 отклонены (индексы с нуля, источник — публичный Podlodka #109).
- SAGE: «сохрани … удали» → «сохранил … удалил» отклонено во всех повторах,
  полезные 7/8 format/typo сохранены. Четыре оставшихся строгих literal mismatch —
  смена типа кавычек при сохранённых словах; они не названы смысловой потерей.
  Переписывание буквальной паузы в boundary также отклонено.

## Цена осторожности и пределы

Фильтр консервативен: большая часть полных редакторских предложений остаётся
исходной. В ранее выполненной целевой agent-review выборке из 30 контекстно
приемлемых изменений проходят 10 (Gemma 5/16, Qwen 5/14). Остальные включают
восстановление неясного ASR, цитат, вводных связок, переформулировку и вопросительную
пунктуацию. Это заметный компромисс; полный редакторский паритет **не заявлен**.
Та выборка не случайная и не является owner/audio gold. Не выдаём количество
accepted edits или прохождение короткого corpus за общее качество длинной правки.

Ограниченные близкие ASR-замены всё ещё используют текстовую близость. Guard не
понимает всю грамматику, различия похожих слов и любую смену смысла пунктуацией.
Выполненное исправление закрывает воспроизведённые RV-018/RV-019, не универсальную
верификацию речи. Нормативный контракт не ослаблен под эти пределы реализации.

**not-run**: native качество refine, полная смысловая проверка/аудио всех 704 строк,
Mac/MPS, ONNX/SAGE в продукте, аппаратная приёмка и обновление работающего демона.
Старые результаты не мигрировались; исправление действует при новых вызовах worker.
