# Proposal

## Why

Отказ YouTube повторяет длинный stderr под зависимыми этапами. Повтор импорта без
скачанного аудио отклоняется, а TUI возвращает пустое подтверждение, создавая цикл.
Владелец также потребовал автоматического обслуживания yt-dlp без ручных команд.

## What Changes

- Полный повтор записи со ссылкой работает до появления аудио и сохраняет исходную
  сессию, конечный бюджет попыток и защиту занятой записи.
- Отказ подтверждённого действия не открывает пустое подтверждение заново;
  текстовые черновики и отдельный сценарий shutdown сохраняются.
- Краткий статус отделён от полной причины; зависимые этапы не копируют stderr.
- Импорт автоматически проверяет официальный stable yt-dlp с кешированием,
  проверкой SHA-256 и атомарной публикацией управляемой пользовательской копии.
  Внешний/пакетный yt-dlp не перезаписывается; при недоступности обновления остаётся
  рабочая копия. Настройка позволяет отключить автообновление.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `processing-pipeline`: ручное восстановление импорта без аудио и краткие состояния ошибок.
- `runtime-settings`: отсутствие цикла повторного подтверждения после отказа.
- `installation-models`: автоматическое обслуживание yt-dlp перед импортом.

## Impact

Archive API, shared workflow/client types, TUI forms, UI error details, ingest tool
manager, worker import, settings/defaults, docs и регресс. Модели не запускаются
для проверки; авторизация браузера не извлекается автоматически.
