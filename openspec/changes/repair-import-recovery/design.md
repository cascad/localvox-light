# Design

## Context

См. proposal. Очередь уже ограничивает отказ фазы тремя попытками; менять бюджет
и автоматически снимать отказ после рестарта не требуется. yt-dlp сейчас устанавливается
через менеджер ОС, поэтому перезаписывать найденный executable нельзя.

## Goals / Non-Goals

Импорт восстанавливается одной существующей командой. Авторизация пользователя,
обход ограничений YouTube и управление сторонним менеджером пакетов не автоматизируются.

## Decisions

- Recook допускает отсутствие аудио только при валидном сохранённом Source.
  Существующая очередь сохраняет kind и сбрасывает prepare/budget; занятая сессия
  и отказ durable commit защищаются прежней mutation lease.
- Полная причина становится отдельным необязательным execution.error. Краткий
  message остаётся состоянием; следующий этап не получает копию last_error.
  UI раскрывает причину отдельно, TUI использует консоль.
- Пустые подтверждения не являются черновиком; после HTTP-ошибки не восстанавливаются.
  Текстовые формы и shutdown сохраняют текущую политику.
- Новый ingest-модуль обслуживает sidecar в пользовательском .localvox/tools/yt-dlp.
  Официальные standalone assets Windows/macOS/Linux выбираются по платформе.
  HTTPS, stable tag, SHA2-256SUMS и проверка --version предшествуют публикации.
  Версионные каталоги и атомарный state-файл не заменяют исполняемый открытый файл.
- File lock сериализует обновление, ожидание ограничено. Успешная проверка кешируется
  на сутки, неуспешная на час; недоступное обновление не ломает рабочий fallback.
  Последние две управляемые версии сохраняются; очистка не касается чужих файлов.
- HTTP/размеры/время ограничены; инструментальные проверки не запускают модели.
  Настройка AUTO_UPDATE включена по умолчанию и видна в каталоге.

## Risks / Trade-offs

- Старая версия может не работать с YouTube → обновление помогает совместимости,
  но 429/CAPTCHA остаются явным отказом источника, без циклических скачиваний.
- Повреждение state/обрыв публикации → выбирается только проверенный executable,
  следующая попытка восстанавливает кеш, fallback не перезаписывается.
- Native ОС различаются → чистые platform/transport/clock проверки и Windows
  реальный binary smoke; Mac/Linux native остаются not-run.

## Migration Plan

Аддитивные поля API; старые executable и настройки не удаляются. Новая настройка
off возвращает прежнее поведение. Комплект готовится локально без замены F:\lv.
