# Design

## Context

Список рисуется двумя строками из Session; queue уже опрашивается независимо раз
в три секунды и содержит phase/position/retry. Runtime имеет монотонный now_ms,
но без событий перерисовывает раз в секунду. Темы уже содержат semantic colors.

## Goals / Non-Goals

**Goals:** один небольшой presentation helper для состояния/символа/подписи,
устойчивые две строки, 100 ms кадры только при показанном активном архиве.

**Non-Goals:** изменение scheduler/protocol, новый poll/thread, достоверность
серверного running сверх существующего ответа, переоформление всех панелей.

## Decisions

- Session.job задаёт статус; matching queue только дополняет phase/position/retry.
  При несовпадении ответов детали не берём. Не выводим состояние из наличия файла
  либо прошедшего времени; queue не становится вторым конкурирующим источником.
- Символ занимает одну колонку: braille snake / ASCII `|/-\\` для running,
  отдельные статические знаки для остальных состояний. Recording отображается
  отдельно в подписи, если обработка выполняется одновременно.
- Подпись состояния/фазы идёт в начале второй строки, чтобы её было видно в узкой
  колонке; у готовой записи сохраняются дата/длительность. Заголовок остаётся ink,
  индикатор/статус/фаза имеют semantic color; выбранная строка сохраняет эти цвета.
- Ошибка sessions/queue даёт static `?`/«нет обновления» до успешного опроса.
  Очередь уже независимо ограничивает частоту запросов; кадр только рисует.
- Runtime сравнивает animation frame key при существующем 50 ms event poll.
  Отдельный таймер/нить и глобальные 10 FPS без активных записей не нужны.
- Фильтр — отдельная строка App, проекция над полным sessions без удаления данных.
  selected относится к видимому списку; refresh сохраняет выбор по ID. Ввод фильтра
  не меняет открытый документ/плеер; Enter открывает видимую запись. Явный переход
  к записи извне очищает фильтр только если она им скрыта.
- По уточнению владельца от 2026-11-10 ввод фильтра — явное состояние App: при фокусе списка первый Slash/точка RU включает его без добавления символа. Вне ввода j/k (о/л RU) и стрелки выбирают строки; обычная печать сама поиск не включает. Внутри ввода все печатные символы, включая j/k/q/g, двоеточие, вопрос и второй Slash, буквальны. Backspace удаляет, Ctrl+U очищает запрос без выхода; Esc очищает и закрывает режим. Enter открывает видимый результат и закрывает ввод; при отсутствии совпадений остаётся инертным. Tab/Shift+Tab уводят фокус и завершают ввод, сохраняя фильтр. Возврат в список не включает редактирование сам по себе: новый Slash продолжает запрос. Пустой активный поиск также явно виден в подсказке. F8/F9/F10/Ctrl+Q сохраняют глобальное действие.
- Терминальный KeyEvent содержит символ, не portable physical scancode. В командном
  контексте поддерживаем явные соответствия RU/EN клавиш (g/п, Slash/точка и другие),
  не пытаемся угадывать раскладку введённого текста. Формы/фильтр остаются Unicode.

## Risks / Trade-offs

- Необычный шрифт/NO_COLOR → ASCII и существующие 16/no-color настройки, символы
  одного display width проверяются тестом. Цвет не единственный носитель смысла.
- Ответы приходят разновременно → matching state, без выдуманной фазы; live данные
  остаются снимками с существующей задержкой опроса, не гарантией heartbeat worker.
- Новое оформление меняет snapshots списка → принять только просмотренные diff,
  проверить разные темы/размеры, анимацию и настоящий ConPTY без личного архива.

## Migration Plan

Собрать только TUI; сервер/API совместимы, перезапуск демона не нужен. Откат —
предыдущий TUI. Если файл текущего клиента занят, не завершать его автоматически:
собрать комплект в отдельный каталог для ручного запуска.
