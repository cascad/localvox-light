# Proposal

## Why

По замечанию владельца 2026-11-10 список TUI должен сразу различать обработку и
очередь. Сейчас строка целиком одноцветная, `running` обозначен неподвижной точкой,
а запись звука скрывает состояние раннего STT.

## What Changes

- Добавить компактную цветную анимацию для серверного состояния `running`, отдельные
  неподвижные символы очереди, ожидания нового куска, отмены, ошибки и готовности.
- Сохранить отдельный признак записи звука; состояние понятно без цвета, есть ASCII.
- Подписать состояние и известную фазу/позицию во второй строке записи, не сдвигая
  название, выбор и прокрутку. При ошибке обновления заморозить анимацию и явно
  отметить неподтверждённое состояние.
- Использовать существующие semantic colors для индикаторов/фаз; поддержать тёмную,
  светлую, 16-color и no-color темы без полной смены оформления.
- По уточнению владельца: локальный фильтр списка по первому `/`, навигация j/k вне ввода; второй `/` и командные буквы остаются текстом запроса. Esc очищает и закрывает поиск. Соответствующие RU/EN клавиши работают вне ввода, текст в формах не меняется.
- Уточнение 2026-11-11: `l` / `д` вне ввода в списке архива открывает выбранную запись как Enter; поиск и формы сохраняют эти символы как текст.
- В области конкретной записи `h/l` / `р/д` без модификаторов действуют как существующие стрелки влево/вправо; плеер и ввод не получают этой горизонтальной привязки.
- Дополнение владельца: в меню разделов `l` / `д` без модификаторов также выбирает подсвеченный раздел, как Enter.
- Обычный выход q/й заменить на два последовательных нажатия с интервалом до 500 ms;
  другая клавиша, вставка, смена контекста или таймаут отменяют ожидание. F10/Ctrl+Q
  остаются немедленными, ввод текста не становится подтверждением выхода.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `archive-playback`: ARCH-010–012, состояния, фильтр списка и клавиши TUI.

## Impact

TUI render/runtime, существующие `/sessions` и `/queue`, tests/snapshots/ConPTY,
пользовательский справочник. Scheduler, серверные ответы, модели и UI не меняются.
Рабочий демон/архив не затрагиваются. Это отдельное небольшое замечание по кандидату,
не общий рефакторинг и не закрытие reference/default/hardware gate раннего STT.
