# Меню и безопасный выход · 2026-11-11

`l` / `д` без модификаторов выбирает подсвеченный раздел через существующий Enter.
Все семь разделов проверены; палитра команд, формы и модификаторы защищены.

Обычная `q` / `й` теперь требует второго Press за 500 ms. Первая только включает
короткую подсказку, следующая другая клавиша/команда/вставка, смена контекста или
просрочка её сбрасывает. Clock — существующий монотонный App.now_ms; новых потоков,
таймеров или input-speed эвристик нет. Runtime перерисовывает смену состояния
подсказки в обычном poll; рабочий status не затирается. F10/Ctrl+Q немедленны.
Известные Repeat/Release не подтверждают; legacy VT без release/repeat событий
не позволяет гарантировать физическое отпускание между одинаковыми символами.
