# Навигация списка и явный поиск · 2026-11-10

Владелец заменил прежний автоматический ввод фильтра явным режимом по Slash.
ARCH-011/012 сохранены, неархивированные planning artifacts уточнены;
[исходные проверки](implementation.md) описывают предыдущий срез.

## Реализация

Вне ввода j/k (о/л RU) и стрелки выбирают запись. Первый Slash/точка RU включает
поиск; второй Slash, командные буквы, двоеточие и вопрос вводятся буквально.
Esc очищает и завершает ввод, Ctrl+U только очищает. Успешный Enter и Tab завершают
ввод, сохраняя запрос; новый Slash продолжает его. При нуле совпадений Enter инертен.
Refresh сохраняет режим и выбранный видимый ID; документ/звук до Enter не меняются.
F6 завершает ввод и передаёт фокус плееру; F10/Ctrl+Q остаются глобальными.
Пустой ввод имеет явную подсказку и тонкий указатель, запрос — цвет аргумента.

## Test-run

`cargo test --locked -p localvox-light-terminal --jobs 2 -- --skip runtime::paste_probe --test-threads=2`:

- 153 lib passed / 2 ignored; 2 теста отдельного paste WIP исключены.
- 2 IO, 4 настоящих ConPTY, 2 run-script passed; mpv hardware test ignored.
- EN/RU j/k и Slash, буквальный второй Slash/командные буквы, refresh,
  Tab/Enter/Esc/Ctrl+U, пустой результат, продолжение запроса и глобальные клавиши.
- ConPTY: `//jk` → буквальный запрос → Esc → j/k → `/` → фильтр → Enter,
  затем русские команды времени/общего поиска. Частный HTTP/терминал, без архива,
  буфера обмена или настроек терминала владельца.
- Просмотрены изменения подсказок и границ их стилей; добавлены три snapshots:
  навигация, пустой ввод и буквальный запрос j/k. Финальный строгий прогон — `INSTA_UPDATE=no`.

Старый ConPTY assert «не более двух HTTP reads за наблюдение кадров» дал отказ при
пересечении штатного poll в параллельном прогоне. Бюджет теперь учитывает фактическое
время, два list reads за 3 s и пару уже начатых запросов; опрос на каждом кадре
по-прежнему превышает бюджет. Дедлайны и механизм ввода не менялись.
