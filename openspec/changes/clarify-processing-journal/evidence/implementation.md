## Контракт и реализация

PIPE-022 добавлен в delta этого change по согласованному владельцем поведению;
main specs не синхронизированы. PIPE-011 остаётся принятым требованием учёта времени.

Координатор сохраняет scope recording/final/import (unknown при недоступных метаданных),
корневая операция worker передаёт контекст дочернему процессу и stage-фактам.
Поля необязательны: старые события остаются «Проход · контекст не записан».
Ни название записи, ни UUID не используются для восстановления контекста.

UI и TUI строят контекст → этап → содержательные операции → логи/команду.
Транспортные prepare/text не дублируют этапы обработки. Команды, исходные ID,
измеренные таймеры и ошибки сохраняются в подробностях и копии; ошибка поднимает
индикатор свёрнутой ветки. Завершение процесса не выдаётся за проверенный артефакт.
Незапрошенные refine/cleanup объединены в компактную ветку.

Время ветки — union известных worker-интервалов загруженного окна («измерено»),
диапазон событий подписан отдельно. Workflow добавляет фоновые worker-интервалы
в общий union этапов, не складывает пересечения и не заменяет неизвестное нулём.
Остаток назван «вне измеренных этапов»; он не объявляется целиком ожиданием.
