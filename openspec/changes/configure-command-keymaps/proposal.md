# Proposal

## Why

Владелец просит команды по физической клавише во всех раскладках UI и опциональный
конфиг TUI для терминалов, передающих только символы. Текущая таблица RU/EN этого
не гарантирует; браузерное копирование также зависит от event.key.

## What Changes

- Буквенные UI hotkeys используют physical code; ввод/IME сохраняют свой текст.
- TUI получает opt-in JSON keymap через --keymap / LOCALVOX_TUI_KEYMAP. Переопределения
  переводят пришедшие символы в штатные командные позиции; RU/EN остаётся default.
- Одна нормализация для команд, qq, Ctrl-команд и явного Ctrl+V; буквальный ввод и
  protocol paste не преобразуются. Ошибочный config отклоняется до запуска клиента.
- Проверки нестандартных раскладок, документация US-ID, CLI и real ConPTY.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `archive-playback`: ARCH-017 — независимые от текста команды UI и явная настройка TUI.

## Impact

UI DocumentPane и TUI input/App/CLI/reconnect; clipboard, API, pipeline и данные
архива сохраняют прежние контракты. Это не обещание восстановления физического
кода из обычного терминального текста и не эмуляторная ветка.
