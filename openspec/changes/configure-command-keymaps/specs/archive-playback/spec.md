# Spec Delta

## ADDED Requirements

### Requirement: ARCH-017 Команды и раскладки клавиатуры

Буквенные команды UI SHALL зависеть от physical key code и модификаторов, а не
символа текущей раскладки. Формы, contenteditable и IME SHALL сохранять исходный
ввод; повторное/несоответствующее сочетание SHALL не запускать команду.

TUI SHALL поддерживать явно выбранный JSON keymap (--keymap или LOCALVOX_TUI_KEYMAP)
с переопределениями символов команд, сохраняя RU/EN поведение без файла. Настройка
SHALL единообразно действовать в обычных/Control-командах, фильтре, paste shortcut и
выходе qq/Ctrl+Q; буквальный ввод и вставка SHALL не преобразовываться. Reconnect
SHALL сохранять keymap. Invalid config SHALL явно отклоняться до terminal mode и
запуска демона. Конфиг SHALL не выдавать символ за достоверный physical scan code;
не доставленные терминалом события восстановить невозможно.

#### Scenario: UI в другой раскладке
- **WHEN** в «Текст» приходит Ctrl/Meta+Shift с code=KeyC и произвольным key другой раскладки
- **THEN** копируется весь документ; code другой клавиши, IME/repeat/редактор не запускают команду.

#### Scenario: Настроенные терминальные команды
- **WHEN** пользователь выбрал keymap и нажимает настроенные символы, в том числе с Ctrl или как qq
- **THEN** выполняются штатные контекстные команды; в форме/фильтре обычные буквы и paste остаются исходным Unicode; переподключение сохраняет соответствия.

#### Scenario: Ошибочная настройка
- **WHEN** файл отсутствует, слишком велик, повреждён, имеет неверную версию или невалидные соответствия
- **THEN** клиент сообщает причину и не начинает terminal session/запуск сервера.
