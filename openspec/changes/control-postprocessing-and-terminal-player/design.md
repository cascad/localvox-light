# Design

## Context

См. proposal.md. После уточнения владельца автоматический путь — обязательный STT и существующая опциональная summary. Refine/cleanup остаются явными ручными операциями. Исторические проверки предыдущей итерации с тремя автоматическими переключателями сохраняются отдельно, текущий контракт уточнён delta.

## Goals / Non-Goals

**Goals:** исключить незапрошенные вызовы LLM, сохранить первичный STT и уже готовые производные, показать точный план задания и сделать плеер управляемым с клавиатуры.

**Non-Goals:** ускорение самой модели, отмена уже работающей внешней генерации, измерение качества модели и физическая аппаратная приёмка.

## Decisions

- Новые автоматические задания помечаются follow_settings. Их план содержит summary по существующему переключателю, refine=false, cleanup=false; старые env-флаги очистки больше не включают её автоматически. Discovery использует тот же план. Остальной Config остаётся snapshot/Restart. Ручные Text/Summary и старые jobs без признака сохраняют точный запрос.
- В общем каталоге UI/TUI остаётся существующая summary. Обязательный STT не имеет переключателя отключения. Устаревшие автоматические ключи очистки не предлагаются в настройках; явные ручные действия и CLI сохраняются.
- Ненужные Pending Text/Summary пропускаются без worker, с сохранением времён и первичных данных. API показывает актуальную политику ещё не начатых этапов, а состояние Running и подтверждённые артефакты сохраняют фактический смысл.
- Текст без processed.json — чтение той же первичной версии через общий resolver обеих вкладок. API сообщает from_transcript=true; UI/TUI показывают источник и не изображают LLM-очистку или её статистику. Чтение не создаёт квитанций/processed.json. Существующая ручная очистка остаётся pinned; повреждение существующего файла не скрывается fallback.
- Job сохраняет phase_queued_at/phase_started_at; старые отсутствующие поля остаются неизвестными. Схема получает execution: текущее состояние, текущий этап/фаза, начало, следующие шаги, retry_at и последний сигнал. Нет задания, backoff, недоступная очередь/координатор и отсутствие сигнала имеют разные сообщения. Событие Running без актуального задания не доказывает живой процесс.
- Каждый захват фазы получает execution_id. Метаданные журнала связывают его с конкретной operation; повторный запуск не делает старую незавершённую запись живой, а запоздавшее завершение предыдущей операции не сбрасывает новую связь. Завершение операции сохраняет монотонную elapsed_sec; длительность видна и в свёрнутой строке. Без известных границ время обозначается неизвестным.
- Ответ схемы содержит время снимка. При ошибке запроса UI/TUI сохраняют доступные результаты, обозначают неподтверждённое выполнение и замораживают таймеры на последнем полученном состоянии; после восстановления запрашивают актуальное исполнение. Состояние операции в журнале подтверждается только соответствующей активной фазой.
- Координатор сообщает запуск/preflight/готовность/остановку. Перед новым worker отмечается начало этапа, включая загрузку модели. Наблюдение за живым дочерним процессом обновляет сигнал, не сбрасывая старт и счётчики. Сбой отдельного выполнения перехватывается с фиксацией ошибки и сохранением lease до освобождения; неожиданный выход координатора отражается в API.
- mpv остаётся единственным терминальным backend. Seek — отдельная IPC-команда без повторного load, снимает границу фрагмента и сохраняет pause. F6 переводит фокус на полосу; Left/Right ±5, Home/End, Space, g для времени. Глобальные Alt+Left/Right ±15 и p сохраняются. Формы перехватывают текст до хоткеев.
- Регрессия обнаружила обрывы коротких POST на Windows при раннем Connection: close. Терминальный HTTP-клиент освобождает соединение после ответа через отключённый idle pool; раннее полузакрытие не запрашивается. Повтор изменяющего запроса не добавляется. Конкурентные короткие импорты и независимость control/documents проверяются отдельно.

## Risks / Trade-offs

- [Долгий текущий LLM-этап] → завершается и сохраняет результат; перед следующей summary проверяется её настройка. Мгновенная отмена не обещается.
- [Старая очередь без происхождения флагов] → сохраняем её намерение, явно документируем миграционную границу; не переинтерпретируем ручную команду.
- [Неподтверждённая скорость на двух часах] → тестируем отсутствие вызовов отключённых фаз, не заявляем численный выигрыш модели.
- [Маленький терминал] → полоса и подсказки проверяются на узкой/низкой геометрии; ошибки проигрывания остаются видимыми.

## Migration Plan

Нужна пересборка нового комплекта и обычный перезапуск по решению владельца; работающий демон при разработке не трогаем. Старые jobs читаются с прежними флагами, новые автоматические — следуют настройкам. Rollback читает дополнительные поля serde как неизвестные, сохранённые артефакты совместимы.
