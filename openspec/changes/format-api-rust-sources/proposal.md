# Форматирование API без изменения поведения

## Why

Продолжение запрошенной владельцем очистки проекта. В предыдущем срезе общий
`cargo fmt -p localvox-light-api -- --check` выявил старые отличия форматирования
в build.rs, bin/*.rs, archive.rs, chat.rs и http.rs. Отдельный форматирующий commit
убирает этот шум, сохраняя читаемость следующих функциональных diff.

## What Changes

- Применить штатный rustfmt только к localvox-light-api и проверить весь diff.
- Убедиться, что изменения ограничены оформлением; не менять значения, запросы,
  подтверждения, контракты или поведение.
- Выполнить проверки API по риску изменения и добавить проверку форматирования
  этого пакета в существующий CI.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет. Только форматирование/инструменты, `skip_specs: true`.
Принятые требования API/ARCH/CHAT/CFG и известные gaps сохраняются.

## Impact

Исходники localvox-light-api, CI и evidence. Нет новых зависимостей и миграций.
Пользовательский архив, работающий демон, модели и интерфейс не затрагиваются.

Отдельный design.md не создаётся: условия его создания из CLI instructions
(архитектура, новые зависимости, миграции или неопределённость решения) здесь
не применяются. Спецификации пропущены по metadata, не ради сокрытия поведения.
