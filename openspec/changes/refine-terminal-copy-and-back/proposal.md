# Proposal

## Why

Владелец 2026-11-11 просит копировать выбранную реплику по y и возвращаться через
Esc по уровням. Сейчас y всегда копирует документ, а Esc из деталей прыгает сразу
в меню, поэтому выбор/чтение списка требуют лишних переходов.

## What Changes

- В «Реплики» y/н копирует только текст выбранной реплики; Ctrl+Y и «Копировать
  документ» сохраняют полное копирование. «Текст» по y остаётся целым документом.
- Esc: закрытие overlay/ввода → детали → список → меню; из фокуса плеера — детали.
- Запись, открытая из поиска/очереди, возвращается в родительский список с выбором;
  возврат сохраняет аудио и не открывает другую запись автоматически.
- Заметки открывают детали через Enter; неактивный фильтр сохраняется при возврате
  в меню, активный ввод по Esc сбрасывается как раньше.
- Обновить подсказки/US-ID, проверить Unicode, пустой выбор, late replies,
  overlays, список/контексты и живой PTY.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `archive-playback`: ARCH-016 для contextual copy/back, уточнение ARCH-011 для
  неактивного фильтра и иерархического Esc.

## Impact

App/navigation/copy actions, TUI help/footer и проверки. API, browser UI, модели,
pipeline, архив/настройки и системное воспроизведение при возврате не меняются.

Уточнение ARCH-011 зависит от `add-terminal-session-activity`, где требование
добавляется впервые; его актуальная delta согласована с этой работой. Самостоятельный
archive нового change до переноса исходного ARCH-011 невозможен. Sync/archive в
этой работе не выполняется, открытая аппаратная приёмка прежнего change сохраняется.
