# Design

## Context

См. proposal.md. y и Ctrl+Y вызывают CopyDocument с полной copy_text projection;
Esc без overlay всегда устанавливает focus=0. Queue/Search Enter переключает View
в Archive, а Notes Enter ещё не переводит фокус в детали.

## Goals / Non-Goals

**Goals:** единое движение на один уровень и безопасное contextual copy.

**Non-Goals:** автопросмотр, история произвольных экранов, изменение браузера/плеера,
clipboard backend, запросов моделей или формата данных.

## Decisions

- Полная copy_text остаётся прежней для Ctrl+Y/экспорта. Отдельная CopyReply action
  берёт выбранный TranscriptLine.text через get(), safe_text и существующий Task::Copy.
  Console/редакторы имеют прежний приоритет; выбранная реплика доступна и через палитру.
- По уточнению владельца выбранный SummaryBlock.text также доступен по y/н и через
  CopySummaryBlock в палитре. Явный выбор по tab/item через get(), без разбора строк
  рендера. Пустой/устаревший item не даёт fallback на весь документ. Общие Task::Copy,
  Ctrl+Y, CopyDocument, экспорт и обработка ошибок остаются прежними.
- Общий back() для уровней focus: player→details→list→menu. Overlay handlers выполняются
  раньше. Неактивный фильтр Esc не перехватывает; активный сбрасывается как раньше.
- Один типизированный родитель Queue/Search вместо стека истории. Он хранит key
  задания (session) или смысловые поля hit и offset списка. Возврат ищет key заново,
  безопасно обрабатывает удаление/перестановку, меняет epoch и не вызывает select_session.
  Switch/явная новая сессия отменяют старого родителя. Никаких Stop/Load при back.
- При уходе из результатов незавершённый Search intent перестаёт быть pending;
  его ещё не отправленные effects удаляются, late response отсечён epoch. Новый
  запрос автоматически не повторяется, предыдущие результаты остаются доступны.

## Risks / Trade-offs

- Потеря фильтра/выбора → unit матрица всех View, родительских переходов и refresh,
  real PTY для уровней/сохранения аудио; подсказки и US-ID обновляются вместе.
- Скопировать лишнее/устаревшее → выбор по item текущей epoch, пустые/out-of-range
  проверки, Unicode/partial update и отсутствие speaker/original/provenance в y.
- Изменился прежний Esc сброса → явное описание активного/неактивного фильтра,
  согласование соответствующей неархивированной delta и обновление визуальных подсказок.
