# Spec Delta

## ADDED Requirements

### Requirement: RUN-006 Явное завершение LocalVox

TUI SHALL предоставлять отдельное действие «Завершить LocalVox» в палитре.
Обычный выход SHALL закрывать только клиент. Полный выход SHALL требовать явного
подтверждения с адресом подключённого демона и предупреждением о закрытии записи
и прерывании обработки с восстановлением очереди при следующем запуске.
Демон SHALL использовать штатную ограниченную по времени остановку компонентов,
а не убийство процессов по имени. Запрос SHALL подчиняться авторизации, проверкам
origin/host и лимитам API; после начала остановки новые mutations SHALL отклоняться.
Клиент SHALL показывать ожидание и закрываться автоматически только после ответа
об успешном завершении cleanup. Ошибка, timeout или потерянный ответ SHALL не
считаться успехом и не запускать автоматический повтор или новый демон.

Код: [daemon](../../../../../crates/localvox-light/src/main.rs),
[HTTP](../../../../../crates/localvox-light-api/src/http.rs),
[TUI](../../../../../crates/localvox-light-terminal/src/app/commands.rs).
Проверки: [coverage](../../../../evidence/coverage.md).

#### Scenario: Обычный выход и отмена
- **WHEN** пользователь выходит из TUI обычным способом либо отменяет подтверждение полного выхода
- **THEN** запрос остановки демону не отправляется.

#### Scenario: Полный выход
- **WHEN** пользователь подтверждает завершение подключённого LocalVox
- **THEN** запись закрывается, owned обработчики завершаются штатно, незавершённая очередь остаётся восстанавливаемой; TUI ждёт результат и после успешного ответа закрывается.

#### Scenario: Остановка не подтверждена
- **WHEN** завершение компонента не удалось либо результат запроса не получен
- **THEN** клиент остаётся открытым с диагностикой; повтор и запуск демона автоматически не выполняются.

#### Scenario: Неподтверждённый или посторонний запрос
- **WHEN** нет авторизации, явного подтверждения или runtime не поддерживает остановку
- **THEN** запрос отклоняется без изменения состояния демона.
