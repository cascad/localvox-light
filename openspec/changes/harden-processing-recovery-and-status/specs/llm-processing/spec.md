# Spec Delta

## ADDED Requirements

### Requirement: LLM-007 Явное отсутствие сводки

Если summary пропущена, API, UI и TUI SHALL показывать skipped и сохранённую
причину вместо «ещё не создана», ожидания или готового файла. Отсутствие распознанных
слов SHALL отличаться от случая, когда модель не создала содержательного ответа
по непустому тексту. Последний SHALL не утверждать, что исходная расшифровка пуста.
Пользователь SHALL иметь явную полную переварку с сохранённого аудио.
Уже сохранённый пропуск SHALL не вызывать автоматическую переварку.

[summary API](../../../../../crates/localvox-light-api/src/archive/documents.rs),

#### Scenario: Короткая речь без сводки
- **WHEN** есть одна непустая реплика, но модель не создала содержательной сводки
- **THEN** «Сводка» и «Ход» показывают пропуск с причиной, текст доступен,
  полная переварка со STT вызывается только пользователем.

#### Scenario: Тишина
- **WHEN** распознанных слов нет и summary не запрашивалась у модели
- **THEN** причина прямо сообщает об отсутствии распознанной речи.

#### Scenario: Текущий запуск после ошибки
- **WHEN** новый запуск создал проверенный результат после старого отказа
- **THEN** результат доступен независимо от старой истории, старый отказ не
  инициирует автоматическую полную переработку.
