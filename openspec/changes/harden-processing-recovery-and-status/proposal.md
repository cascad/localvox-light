# Proposal

## Why

Владелец прислал 2026-11-23 Mac screenshots: импорт долго ждёт yt-dlp, отсутствующая
ASR-модель вызывает серии отказов, палитра скрывает команды после видимого края,
а пропущенная summary выглядит готовой в «Ход» и «ещё не созданной» в «Сводке».
По уточнению владельца, в тексте есть одна короткая строка. Это свидетельства
пользователя, не воспроизведение его записи на машине агента.

## What Changes

- Три попытки фазы, затем сохранённый Failed только до ручного повтора; без
  автоматических возвращений через часы и сброса бюджета при рестарте/Stop записи.
- Конечные сетевые попытки yt-dlp без умножения внутренних retry и очереди,
  ограниченное ожидание необязательного названия, сохранение причины.
- Единая полная переварка выбранной записи по r с аудио и подтверждением;
  старые попытки остаются историей, не отменяют новые подтверждённые результаты.
- В UI/TUI summary сообщает «пропущена» и причину вместо обещания будущего файла;
  отсутствие речи отличается от несодержательного ответа модели. Ручной повтор доступен.
- Палитра показывает диапазон/общее число/продолжение, поддерживает страницы,
  Home/End и короткий терминал. Новые ошибки этапов имеют измеряемое начало/конец.
- Follow-up браузерного прогона: устранить гонку существующего Stop во время
  неподтверждённого Start (REC-001/003, US-002), сохранив доступность остановки.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `processing-pipeline`: PIPE-010/011, конечное восстановление и честный итог.
- `llm-processing`: LLM-001/004, причина отсутствия summary в готовом результате.
- `archive-playback`: доступность команд и ручные операции выбранной записи.

## Impact

Durable jobs/coordinator/prefix, yt-dlp boundary, workflow/summary API и оба клиента,
палитра, справочник и регрессы через частные файлы/HTTP/PTY/browser. Без новых весов,
чужого архива, автоматического удаления или полной переработки готовых записей.
