# Проверка

Windows: `cargo test --locked -p localvox-light-terminal` — 265 модульных тестов и 20 интеграционных прошли, включая 13 ConPTY. Четыре теста с отметкой ignored не запускались этим вызовом. `cargo test --locked -p localvox-light-api --lib http::tests::settings::` — два теста прошли; родительский HTTP-тест отдельно запускает дочерний fixture. Обновлены и проверены 11 снимков отрисовки.

В Windows TUI проверены состояния шапки при готовности движка, старте, записи, остановке и ошибке чтения статуса при ширине 35, 80 и 140 колонок. В тесте с ConPTY клиент получает F9 внутри другой формы, отправляет название по Enter, дожидается подтверждения и отправляет остановку по F8 из открытой формы. Переключение между значениями настройки проверено с русской и английской раскладками, стрелками и Ctrl+n/p. Текстовая форма сохраняет те же символы в названии.

В изолированном HTTP fixture зарегистрированы устройства захвата. Сохранение T-one, затем GigaAM оставляет включённый системный источник и счётчик переоткрытий без изменений. Переключение захвата меняет счётчик, повторное сохранение эквивалентной настройки сохраняет поток.

В CPAL 0.18.2 macOS tap привязан к UID выбранного выхода и его потоку 0. Поэтому проверка браузером не устанавливает, какой выход использует программа звонка. Источник — [реализация CPAL](https://docs.rs/crate/cpal/0.18.2/source/src/host/coreaudio/macos/loopback.rs). В [нативной проверке](../../../../docs/behavior-testing.md) описано сравнение обеих фраз в сохранённом аудио. Запись собеседника на Mac и причина прерывания у владельца в этой сессии не подтверждены.
