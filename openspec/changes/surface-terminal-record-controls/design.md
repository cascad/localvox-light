# Design

## Context

F9 и F8 зарезервированы обработчиком событий терминала. Состояние приходит из API записи. Палитра уже поддерживает клавиатурную раскладку и несколько способов перемещения.

## Goals / Non-Goals

Подсказать актуальную команду до открытия палитры. Сохранить глобальную доступность остановки и буквальный ввод в текстовых полях.

## Decisions

Оставить текущую пару клавиш. Разместить команду в начале строки подсказок, чтобы шкалы и длинное название не могли её вытеснить. Общий разбор клавиш использовать только для списков выбора. Списку и строке подсказки выделить отдельные области.

Проверить сохранение STT в изолированном API с зарегистрированным захватом. Перед переоткрытием сравнить запрошенную конфигурацию с действующей: повторное сохранение того же устройства или сброс к равнозначной предустановке не должен прерывать аудиопоток. На Mac сравнить устройство вывода звонка с устройством захвата и проверить записанный системный канал при выключенном микрофоне.

## Risks / Trade-offs

Открытый поток может передавать тишину. Проверка настроек изолирует причинную связь с переоткрытием устройств, но не измеряет маршрутизацию звука конкретного звонка.
