## Контракт и изменение

По прямому поручению владельца RUN-007 уточнён в delta этого change:
во всех компактных подтверждениях работают и отдельный s/ы, и Enter.
Ограничение Enter только полным выходом из `fix-terminal-relative-seek` отменено.
Предыдущие delta ещё не sync в main; это не утверждение, что RUN-007 уже есть в main.
Design не создавался: архитектура, API и модель данных не менялись.

Общий обработчик формы применяет одинаковые клавиши к сохранению/отмене черновика,
удалению записи/заметки/вопроса, переварке, повтору, отмене, подтверждению документа
и shutdown. Подсказки показывают Enter / s. Сохраняются закреплённая исходная цель,
pending-защита, Esc, Ctrl+S/Ctrl+Enter; Repeat/Release/Paste не подтверждают.
В текстовом редакторе s и новая строка остаются текстом.

State-проверка перебирает s/ы/Enter для всех видов подтверждаемых задач; проверяет
невыполнение от Paste/Repeat/Release/Shift+S, исходную запись/сырой текст заметки,
однократность запроса, локальную отмену черновика и ввод s/Enter в заметке.

с обновлённой подсказкой при отсутствующей сводке, затем пройден без update.

Native-проверки используют реальные терминальные клавиши: удаление записи
отдельно через s и Enter, сохранение настроек и полный выход обоими вариантами,
ожидание HTTP ack и отсутствие повторного запроса. Остальные сценарии PTY также прошли.
Незавершённый вчерашний native-прогон не считается успешной проверкой.
