# Proposal

## Why

Владелец поручил выпустить текущие проверенные изменения. До тега найдена причина
прошлого CI-отказа: подготовленный mpv не был передан нативному тесту через окружение.

## What Changes

- Согласованная версия 0.2.12 во всех манифестах/lock-файлах.
- Setup mpv публикует проверенный абсолютный путь в GITHUB_ENV и при загрузке,
  и при использовании готовой копии; контракт исполняет настоящий Node-скрипт.
- Синтетические тесты явно отключают обновление внешних инструментов.
- Общий UI/TUI HTTP-сценарий раскрывает свёрнутый учёт времени и этап сводки,
  сохраняя проверки арифметики и всех 35 строк настоящего журнала.
- Локальные delivery/installer/media проверки предшествуют push/tag; публикация
  и все пять платформ проверяются по фактическому Actions run и release assets.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

Нет: метаданные выпуска и исправление CI/test tooling, без нового поведения продукта.
`skip_specs: true`; продуктовые изменения описаны предыдущими change.

## Impact

Версии, инструменты CI, synthetic runner, release evidence. Модели, рабочий архив
и настройки установленного приложения не меняются.
