# v0.2.12 не опубликован · 2026-11-25

Коммит `2829e5c6ea5b1125842811951cdac2799e597b50` и аннотированный тег
`v0.2.12` отправлены. [Run 45591052315](https://github.com/cascad/localvox-light/actions/runs/45591052315)
прошёл early publication gate и model sources, но Windows delivery отказал на
новом Unicode fixture: системный ANSI tar не нашёл ZIP в пути с `Ю`.

Это фактический отказ после локального passed на CP1251. Регресс был недостаточен:
`Ю` представим в CP1251, но не в CP1252. Расширение пути китайскими символами
воспроизвело отказ локально; последующий fix отслеживается в
[release-v0-2-13](../../release-v0-2-13/proposal.md).

Задача публикации 2.1 остаётся невыполненной. Тег не перемещается, выпуск не
выдаётся за доступный. Предыдущие локальные результаты сохранены как выполненные
локально, без утверждения о соответствии всем Windows locales.
