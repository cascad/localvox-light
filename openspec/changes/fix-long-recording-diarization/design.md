# Design

## Context

См. proposal.md. `Runner` уже вычисляет voice embeddings при проходе PCM, затем `finish` синхронно группирует всю дорожку. Текст публикуется после этого. Старый average-linkage повторяет O(n³·d) работы; общий heartbeat скрывает подоперацию.

## Goals / Non-Goals

**Goals:** убрать кубическую повторную работу, сохранить смысл average linkage и границы ответственности; дать журналу реальные границы ASR и группировки.

**Non-Goals:** смена нейросети, приближённое разбиение, искусственное ограничение числа фрагментов, остановка текущего процесса или внедрение ранней публикации в старый импорт.

## Decisions

1. Rust `kodama = 0.3.0`, MIT, без runtime dependencies: проверенный nearest-neighbor-chain для Average, O(n²) времени после построения condensed cosine matrix. Источники: [kodama](https://docs.rs/kodama/0.3.0/kodama/), [SciPy](https://docs.scipy.org/doc/scipy/reference/generated/scipy.cluster.hierarchy.linkage.html). Самописный NNC и очередь всех пар добавляют риски/память; приближённое объединение меняет качество.
2. Расстояния исходных пар считаются ровно один раз. Нормы векторов кешируются; матрица f64 снижает накопление ошибки average. Перед выделением — checked arithmetic, бюджет матрицы 256 MiB и try_reserve_exact. Непустые векторы одинаковой размерности и finite input обязательны. Ошибка возвращается обычным Result; cook пишет её в журнал и сохраняет текст без разметки, как при других отказах опциональной диаризации.
3. Дендrogram режется по прежнему правилу: слияние продолжается, пока расстояние не выше порога ИЛИ превышено максимальное число голосов. Метки нумеруются по первому исходному фрагменту. При точных равенствах допустим другой детерминированный порядок слияний, при расстояниях у границы возможна разница float precision; это не битовая совместимость старых номеров.
4. Группировка обёрнута отдельной операцией существующего журнала с длительностью и heartbeat. API/UI/TUI используют имеющийся формат; 100% прохода аудио не означает готовность этапа. Ошибка подоперации явно помечается.

## Risks / Trade-offs

- O(n²) память → явный бюджет 256 MiB, проверка до выделения и сохранение текста при отказе; для ещё более длинных входов нужна отдельно спроектированная exact/ограниченная по памяти кластеризация, без скрытого subsampling.
- Равные расстояния/округление → сравнение разбиений на однозначных примерах, отдельные тесты повторяемости и пороговых границ, прежние модели/пороги остаются.
- Синтетика не равна качеству на архиве → замер отдельно от приёмки; текущий архив не переобрабатывается и не останавливается автоматически.

## Migration Plan

Проверить unit/regression, изолированный release benchmark и общий журнал; собрать новый worker отдельно от исполняемого файла работающего процесса. Обновление начнёт действовать для нового процесса после штатного перезапуска, без изменения старых транскриптов. Откат — предыдущий бинарник, формат данных совместим.
