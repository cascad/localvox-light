# Proposal

## Why

Владелец просит подтверждать полный выход обычной отправкой Ctrl+S, без набора ДА.
Текстовое поле для этого действия создаёт лишний шаг.

## What Changes

- Компактное подтверждение завершения с адресом, предупреждением и клавишами.
- Ctrl+S / Ctrl+Enter отправляет stop; Esc отменяет. Ввод текста не требуется.
- Сохранить ожидание результата, диагностику и обычный client-only выход.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `runtime-settings`: уточнить подтверждение RUN-006 из add-graceful-application-exit.

## Impact

Только TUI dialog/input и его unit/render/ConPTY checks, US-062 и инструкции.
HTTP/lifecycle и остальные формы не меняют поведение. Sync RUN-006 выполняется
после исходного change; исторические результаты его проверки сохраняются.
По следующему поручению владельца внутренний статус ручной проверки Mac удаляется
из README; фактический not-run остаётся в evidence.
