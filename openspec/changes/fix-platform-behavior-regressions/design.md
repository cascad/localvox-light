# Design

## Context

См. proposal. Корень пустого списка подтверждён в коде: runtime отправляет глобальные
запросы с epoch=0, а deletion fence отклоняет epoch ниже нового поколения. Подмена
фильтра или сброс fence по таймеру скрыли бы гонку. Session allocator использует
timestamp + свободный ordinal, который может повториться после удаления.

## Goals / Non-Goals

Один воспроизводимый локальный запуск на каждой поддерживаемой ОС; source tests
и явный выбор проверяемой установленной TUI-сборки, понятные границы аппаратной проверки.
Не использовать пользовательский архив/конфиг, не запускать микрофон/модели и не
выдавать synthetic PCM/null-audio за аппаратную приёмку.

## Decisions

- Отделить принадлежность запроса к поколению от его отменяемости. Глобальный
  запрос несёт реальное поколение, но смена документа не отменяет его/мутацию.
  Pending глобального ресурса ограничен одним запросом независимо от поколения.
- Новая сессия получает UUID в ID и атомарно резервирует каталог; title остаётся
  отдельным пользовательским значением. Старые имена/архивы читаются как раньше.
- Убрать кольцо pre-roll из архивного ChunkLane и сдвиг started_at. Legacy env/CLI
  совместимость не должна возвращать историю. Временный bounded orphan после Start
  — защита при ошибке записи, он не содержит аудио до Start. Polling/network latency
  не трактуется как нулевое время между физической клавишей и принятием команды.
- Подтверждения показывают только s/ы и Esc; одиночная s в редакторе остаётся буквой.
  Однострочный параметр подтверждается Enter, многострочный текст — Ctrl+Enter.
  Палитра нормализует RU/EN и Ctrl+n/p до общей навигации, без применения к редакторам.
- Реальный mpv с null audio проверяет Load/Toggle/Seek/fragment EOF/replay. Команда
  file-local-options допустима только при загруженном файле; штатные idle/loading
  и EOF не являются потерей IPC. Не маскировать транспортные/decoder ошибки.
- Runner на Python stdlib запускает фиксированный manifest групп: native TUI
  state/HTTP/PTY, synthetic recording/storage/API, mpv IPC, GUI unit/browser.
  Ограниченные логи и отчёты в target/behavior; модельные/аппаратные сценарии
  явно not-run. Нет широкого сбора env/секретов. Отчёт содержит platform/commit/
  проверенные бинарники/команды/exit codes и ссылки на локальные артефакты.
  AGENT_TASK.md перечисляет фактические отказы, команды воспроизведения и проверок;
  содержимое логов считается недоверенными данными, baseline под дефект не обновлять.

## Risks / Trade-offs

Смена поколения отменяет глобальную мутацию → Io/runtime/PTY регресс после перехода.
Новый UUID ломает строковые предположения → allocator/API/client проверки и legacy read.
Ожидание mpv зависает → единый bounded IPC deadline и реальный null-audio test.
Локальный runner молча пропускает зависимость → explicit blocked/not-run и ненулевой
exit для незапущенных обязательных групп; готовые setup-команды в отчёте.

## Migration Plan

Сначала регрессы известных цепочек, затем реализация и локальный runner. Старые
записи не переписываются; новые настройки/CLI не включают pre-roll. Обновить US-ID
и evidence. Mac/Linux владелец запускает тот же runner, результаты не приписываются
Windows прогону или чужому release-бинарнику.
