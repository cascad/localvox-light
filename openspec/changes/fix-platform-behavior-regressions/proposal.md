# Proposal

## Why

Проверка владельца на macOS 2026-11-24 выявила исчезающий после удаления список,
лишние минуты pre-roll, разнородные подтверждения, недостаточную навигацию палитры
и отказ mpv. Нужен воспроизводимый локальный набор для Windows/macOS/Linux,
чтобы местный агент получал конкретный отчёт и задание вместо ручного сбора багов.

## What Changes

- Исправить поколение глобальных ответов TUI: старые ответы после мутации
  отклоняются, последующие свежие ответы принимаются без перезапуска.
- Новые сессии имеют непереиспользуемый ID независимо от имени, времени и удаления.
  Сверить удаление файлов/очереди/индексов и не переносить состояние старой записи.
- По прямому поручению владельца убрать pre-roll архивной записи: сохранять
  только звук между принятыми конвейером Start/Stop. Старые env/CLI pre-roll
  не добавляют историю; UI/TUI не обещают pre-roll.
- Подтверждения без текстового ввода показывают `s`/`ы` и Esc единообразно;
  палитра принимает n/p, RU аналоги и Ctrl+n/p. Буквы в текстовых полях остаются текстом.
- Исправить управление mpv на границе загрузки/EOF, воспроизвести реальным mpv
  через IPC с тестовым WAV и null audio.
- Добавить общий локальный runner, изолированные fixtures, отдельные pass/fail/
  not-run, логи, структурированный отчёт и файл задания для местного агента.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `recording`: REC-002 — явные границы вместо истории pre-roll.
- `archive-playback`: навигация палитры и единые подтверждения; новый ID сессии.
  Исчезновение списка и IPC исправляются по существующим ARCH-001/002/005.

## Impact

TUI runtime/Io/App, session allocation, ChunkLane/CLI/settings, player IPC,
unit/HTTP/native PTY tests, cross-platform runner и docs/user-guide.
Аппаратные устройства и пользовательский архив не используются автоматическими
fixtures; фактический локальный прогон на Mac/Linux отмечается отдельно от Windows/CI.
