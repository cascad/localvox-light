# Spec Delta

## MODIFIED Requirements

### Requirement: REC-002 Pre-roll и время начала

Архивная запись SHALL сохранять только аудио между принятыми конвейером командами
Start и Stop. История до Start SHALL NOT попадать в новую запись или сдвигать
started_at назад. Старые настройки pre-roll SHALL NOT добавлять минуты истории.
Оба источника подчиняются одной границе записи; сохранённая длительность определяется
записанными сэмплами, без искусственного дополнения до размера буфера/чанка.

Код: [ChunkLane](../../../../../crates/localvox-light-core/src/pipeline.rs).

При временном отказе создания каталога ограниченный orphan-буфер может содержать
только звук после Start; он не является pre-roll. Удаление этой возможности не
отменяет диагностирование потери устройства, пауз или задержки принятия команды.

#### Scenario: Движок работал пять минут до записи

- **WHEN** пользователь записывает двадцать секунд после длительного ожидания
- **THEN** в обоих источниках отсутствует звук до принятого Start и после Stop,
  длительность не увеличивается на накопленную историю.

#### Scenario: Старая настройка pre-roll

- **WHEN** сохранилось значение pre-roll 300 секунд
- **THEN** новая запись всё равно начинается с принятого Start без добавления истории.

#### Scenario: Неполное кольцо

- **WHEN** запись начата вскоре после запуска и доступна лишь короткая история
- **THEN** даже эта история не добавляется в архив; started_at не сдвигается назад.

#### Scenario: Каталог недоступен

- **WHEN** после Start каталог временно недоступен
- **THEN** повтор создания использует ограниченный буфер только начатой записи,
  а не предшествующего разговора; отказ остаётся видимым.
