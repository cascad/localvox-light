# Design

## Context

См. proposal. Существующий `localvox-profile` уже умеет bounded worker, локальный
Ollama proxy, checkpoints, проверку receipts и численные timelines. Его manifest
пока принимает WAV и запускает только STT/summary. Двухчасовая публичная STT из BL-003
доступна отдельно от пользовательского архива.

## Goals / Non-Goals

Измерить действительные production paths правки, включая последовательный двойной
проход, сохранив исходник. Внутренние компоненты summary NER остаются отдельным
profile-summary-grounding-cost; здесь достаточно общего времени проверок/генерации.
Оптимизацию prompts/пакетов и качество формулировок этот измерительный этап не меняет.

## Decisions

- Добавить явный `--text-only` режим существующего profiler: отдельная строгая
  JSONL manifest schema, отдельные fresh sessions для refine/cleanup/refine-cleanup/
  summary. Повторный ASR исключён; общий режим WAV/queue сохраняется.
- В каждом случае копировать только валидированный JSONL в новую исходную версию,
  задать тестовую session meta. Не копировать старые derived artifacts, имена
  каталогов или настройки пользователя. Сохранять fingerprints входа/worker/NER.
- Переиспользовать worker command env isolation, process supervisor, timeout,
  native proxy и timeline sanitizer. Выход worker проверять по receipts.
- Отчёт содержит только счётчики/времена/хэши, не stdout/stderr, текст, имена или
  сообщения ошибок модели. Входной/выходной текст остаётся в изолированном output.
- Сначала model-free guards, затем один последовательный bounded local run каждого
  пути на публичном материале. Фиксировать residency до/после, не выгружать модели
  пользователя. При timeout/отказе сохранить частичный отчёт и остановить пачку;
  не объявлять неполный прогон измерением полного времени.

## Risks / Trade-offs

- Перенос гипотезы о маленьких пакетах в готовую причину → нативные counters и wall,
  отдельно от статического количества пакетов и исторического инцидента.
- Разный текст после refine → три отдельных исходных пути и явно подписанный chain;
  не суммировать вложенные длительности с wall, не сравнивать принятые edits с качеством.
- Загрузка desktop/GPU и запуск другого LLM клиента → фиксировать известные условия;
  отсутствие контролируемого окружения обозначить ограничением.
- Старый WAV profiler → оставить его параметры/схему и прогнать прежние tests.

## Migration Plan

Только engineering CLI/docs; рабочий демон и пользовательская конфигурация не меняются.
