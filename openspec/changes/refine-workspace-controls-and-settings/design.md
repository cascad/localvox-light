# Design

## Context

См. proposal. Hints каталога не являются значениями и уже
разошлись с coordinator (300 вместо 5 s). Фактические сроки применения сохраняются.

## Goals / Non-Goals

Единый env-источник предустановок каталога, видимые значения и удобный список LLM
адресов. Не менять значения рабочих предустановок ради оформления, не перезаписывать
пользовательский .env, не сохранять токены внутри адресов и не менять API-подключение TUI.

## Decisions

- `.env.defaults` ищется рядом с пользовательским .env, затем в cwd; при отсутствии
  используется копия того же файла из сборки. Bootstrap добавляет только отсутствующие непустые значения
  после пользовательского env, до CLI parse. Contained worker сохраняет startup snapshot.
  Численные/строковые fallback каталога берутся из этого env-файла, не из hint.
- API возвращает `default_value` и путь предустановок; `value/set` сохраняют значение
  пользовательского файла. Секреты исключены. Пустая автоматическая настройка имеет
  явную подпись в обоих клиентах; reset снимает override и возвращает default.
- JSON-массив URL `LOCALVOX_LLM_SERVER_URLS` — классифицированная настройка списка.
  BASE_URL получает options; оба клиента умеют добавить URL в список и выбрать его
  в одном черновике. Сохранение использует существующий атомарный env editor.
- Валидация HTTP(S)/host/no credentials выполняется клиентом и API, max 32 адреса.
  Список перечитывается при запросе настроек, активный адрес требует Restart.
- Визуальные поправки журнала и TUI реализуются вместе, их JRN/TERM-контракты
  обновляются в существующем add-technical-journal-workspace, не дублируются здесь.

## Risks / Trade-offs

- Подмена пользовательских настроек default → только missing keys; tests override,
  reset, startup snapshot и сохранности комментариев.
- Старый API/client → optional default metadata; legacy ответы читаются как раньше.
- Автопоиск пути/устройства нельзя превратить в буквальный путь «Автоматически» →
  подпись отделена от пустого машинного значения.
- Потеря сервера из списка → неизвестный активный URL сохраняется как допустимый
  выбор, добавление не отправляет POST до явного Save.

## Migration Plan

Поставлять .env.defaults с комплектом. Новые поля/API обратно совместимы; старый
.env остаётся override. После сборки обычный перезапуск выполняет пользователь.
