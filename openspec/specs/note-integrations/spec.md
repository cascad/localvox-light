# Note integrations Specification

## Purpose

F2/F5/F6. Слоты, файловые заметки, MCP-назначения и предложения маршрутизации.

Статус контракта: **accepted**, 2026-09-27. Это обязательное поведение,
а не заявление о безошибочности текущей сборки.

## Requirements

### Requirement: NOTE-001 Разрешение слота

SlotRegistry SHALL читать TOML, отклонять пустой набор слотов и более одного default=true, сопоставлять имя/алиас без учёта регистра. При отсутствии default выбирается первый слот из BTreeMap-порядка; «ровно один default обязателен» не соответствует коду. Приоритет конфигурации: explicit, env, cwd slots.toml, сосед exe.

Код: [SlotRegistry, FsIntegration](../../../crates/localvox-light-integrations/src/lib.rs).
Существующая проверка: `file_append_with_aliases_and_default`.

#### Scenario: Нет default

- **WHEN** есть несколько валидных слотов и ни один не default
- **THEN** выбирается первый, а не ошибка.

#### Scenario: Два default

- **WHEN** два слота имеют default=true
- **THEN** загрузка отклоняется.

### Requirement: NOTE-002 Файл или каталог

FsIntegration SHALL отвергать пустой текст, подставлять text/date/time в шаблон и создавать назначения при записи. Существующий каталог либо путь без расширения означает отдельный md-файл; иной путь — append с переводом строки при необходимости. Имя может включать время и slug, но отдельная заметка SHALL получать уникальный файл: совпадение времени/начала текста не разрешает перезапись другой заметки.

Код: [SlotRegistry, FsIntegration](../../../crates/localvox-light-integrations/src/lib.rs).
Существующая проверка: `folder_target_creates_file_per_note`.

#### Scenario: Append без финального newline

- **WHEN** файл уже содержит текст без перевода строки
- **THEN** перед новой заметкой вставляется newline.

#### Scenario: Папка

- **WHEN** слот указывает на каталог
- **THEN** заметка записывается в отдельный md-файл.

#### Scenario: Совпадение имён

- **WHEN** две заметки имеют одинаковое начало и созданы в одну секунду
- **THEN** обе сохраняются раздельно; первая не перезаписывается.

### Requirement: NOTE-003 Чтение и удаление заметок

Файловая интеграция SHALL выдавать заметки с raw и source, отображая дату отдельно. Удаление проверяет границы назначения; файловый слот удаляет совпавшую исходную строку, каталог — файл заметки. MCP-назначение по умолчанию не поддерживает read/delete и сообщает об этом.

Код: [SlotRegistry, FsIntegration](../../../crates/localvox-light-integrations/src/lib.rs), [Archive](../../../crates/localvox-light-api/src/archive.rs).

#### Scenario: Изменён vault

- **WHEN** клиент отправляет удаление заметки
- **THEN** поиск использует исходную строку и файл, не старый числовой индекс.

#### Scenario: MCP только на запись

- **WHEN** запрошено чтение назначения без реализации read_notes
- **THEN** возвращается ограничение, а не доказательство пустого назначения.

### Requirement: NOTE-004 MCP-вызов назначения

McpIntegration SHALL для записи запускать настроенную команду stdio, выполнять initialize/initialized/tools-call и передавать текст в text_arg поверх static_args. Ошибка isError считается отказом. Ответ ждётся с конечным таймаутом (по умолчанию 20 с), чужие id/уведомления не являются ответом. Отсутствие ответа SHALL не считаться доставкой; неопределённый исход учитывается по NOTE-006. Завершение процесса клиента не доказывает откат уже выполненной внешней записи.

Код: [McpIntegration::write_note, McpClient](../../../crates/localvox-light-integrations/src/mcp.rs).

#### Scenario: MCP возвращает isError

- **WHEN** tools/call завершился протокольным ответом с ошибкой
- **THEN** заметка не объявляется успешно сохранённой.

#### Scenario: Молчащий MCP

- **WHEN** ответ не пришёл за лимит
- **THEN** операция возвращает ошибку таймаута.

### Requirement: NOTE-005 Suggest then confirm

Маршрутизатор SHALL предлагать только имена из переданного реестра, удалять дубли, использовать начало текста до 4000 символов; пустой текст/реестр не вызывает модель. Ответ допускает markdown/нумерацию. Промпт просит 1–3 слота, но parse_routing не обрезает результат до трёх. Предложение само не вызывает write_note.

Код: [suggest_routing, parse_routing](../../../crates/localvox-light-llm/src/routing.rs), [Notes](../../../ui/src/Notes.tsx).
Существующая проверка: `parses_and_validates_names` в routing.rs.

#### Scenario: Выдуманный слот

- **WHEN** LLM вернула отсутствующее имя
- **THEN** оно отбрасывается.

#### Scenario: Подсказка

- **WHEN** пользователь запросил предложения
- **THEN** запись не происходит без отдельного действия сохранения.

### Requirement: NOTE-006 Локальная сохранность и статус доставки

Система SHALL сначала сохранять отдельную локальную заметку с устойчивым ID, текстом
и назначением, затем выполнять доставку (DEC-008). Подтверждённая локальная заметка
SHALL читаться после перезапуска независимо от доступности назначения. Статусы
локального сохранения и доставки SHALL различаться; ошибка доставки сохраняет
локальный текст, причину и возможность повторить именно эту заметку.
Ошибка локальной записи SHALL останавливать доставку и запрещать подтверждение
сохранения. При потере ответа внешнего сервиса результат SHALL обозначаться как
неопределённый, а повтор не обещает exactly-once. Дедупликация использует устойчивый
ID, если назначение её поддерживает; возможность дубля должна быть понятна до повтора.
Схема локального хранилища и политика фоновых повторов определяются в BL-021;
неограниченная автоматическая повторная доставка не разрешена.

Код входов: [voice worker](../../../crates/localvox-light-voice/src/lib.rs),
[SlotRegistry](../../../crates/localvox-light-integrations/src/lib.rs),
[MCP adapter](../../../crates/localvox-light-integrations/src/mcp.rs),
[Archive](../../../crates/localvox-light-api/src/archive.rs).
**Implementation gap:** локального outbox нет; [BL-021](../../changes/persist-notes-before-delivery/proposal.md), RV-007.

#### Scenario: Назначение недоступно

- **WHEN** локальное сохранение прошло, а доставка завершилась ошибкой
- **THEN** после перезапуска текст доступен со статусом ошибки доставки; пользователь может повторить доставку.

#### Scenario: Локальное сохранение не удалось

- **WHEN** нельзя надёжно сохранить заметку в локальное хранилище
- **THEN** доставка не начинается, успех не подтверждается, ошибка показана пользователю.

#### Scenario: Ответ потерян после внешней записи

- **WHEN** назначение могло сохранить текст, но подтверждения нет
- **THEN** локальная заметка сохраняется, статус не утверждает доставку или отсутствие записи; повтор учитывает возможный дубль.

## Implementation status

NOTE-002 допускает коллизии имён; NOTE-006 пока не реализован. MCP Drop убивает только непосредственный процесс (RV-007, BL-021). Изолированный mock подтвердил ошибку, timeout, явный повтор и дубль при потере ответа; exactly-once не обещается.

## Observed limitations

Две одинаковые заметки в папку за одну секунду могут иметь одинаковый путь: fs::write не обеспечивает уникальность. Не выдаём append за fsync-транзакцию. MCP Drop не подтверждает очистку всего дерева; pipe-дедлоки/внешняя доставка требуют отдельной сверки RV-007. Конфигурационные примеры остаются в docs/integrations.md.
