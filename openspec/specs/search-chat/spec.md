# Search and chat Specification

## Purpose

F4. Лексический/семантический/гибридный поиск и вопрос к найденным фрагментам.

Статус контракта: **accepted**, 2026-09-27. Это обязательное поведение,
а не заявление о безошибочности текущей сборки.
[Основание принятия и границы](../../baseline.md) ·
[Сверка каждого требования](../../evidence/coverage.md#search-chat).

## Requirements

### Requirement: SEARCH-001 Индексируемые данные

SearchIndex SHALL строить Tantivy-индекс из файлов архива, использовать русскую морфологию и возвращать session/kind/snippet и таймкоды при их наличии. SemanticIndex хранит векторы через настроенный embedding endpoint; изменения сессий требуют обновления индекса. Индексы производные и не являются единственным хранилищем текста.

Код: [SearchIndex::open_or_build/search](../../../crates/localvox-light-search/src/lib.rs), [SemanticIndex::open_or_update](../../../crates/localvox-light-search/src/semantic.rs).
Существующая проверка: `finds_stemmed_russian_word_with_timecode`, `finds_in_summary_paragraphs`.

#### Scenario: Словоформа

- **WHEN** запрошена другая форма русского слова
- **THEN** морфологический поиск может найти индексированную реплику.

#### Scenario: Текст сводки

- **WHEN** слово есть в summary
- **THEN** поиск возвращает фрагмент summary без выдуманного речевого таймкода.

### Requirement: SEARCH-002 Режимы и деградация

search_mode SHALL возвращать пустой список на пустой запрос без вызова embeddings, ограничивать API limit диапазоном 1–50. semantic сообщает свою ошибку; hybrid независимо обрабатывает ошибки каналов и сливает доступные результаты RRF с дедупликацией. При отказе обоих каналов API SHALL вернуть ошибку недоступности поиска. «Ничего не найдено» допустимо только после успешного поиска; ошибка поиска SHALL не превращаться в ответ чата об отсутствии информации.

Код: [Archive](../../../crates/localvox-light-api/src/archive.rs).

#### Scenario: Ollama недоступна

- **WHEN** hybrid получил рабочие лексические результаты и ошибку semantic
- **THEN** выдаются лексические результаты.

#### Scenario: Оба канала отказали

- **WHEN** оба канала hybrid завершились ошибкой
- **THEN** API сообщает отказ поиска, а чат не выдаёт его за отсутствие данных и не вызывает LLM.

### Requirement: SEARCH-003 Занятый semantic

semantic_hits SHALL брать SemanticGuard без ожидания; занятый индекс сообщает «занято». Внутри guard индекс может синхронно перестраиваться; hybrid при этой ошибке использует lexical. Фоновый прогрев и отмена при новой работе описаны PIPE-013.

Код: [Archive](../../../crates/localvox-light-api/src/archive.rs).

#### Scenario: Конкурентный запрос

- **WHEN** другой semantic запрос уже удерживает guard
- **THEN** новый не занимает поток ожиданием этого guard.

### Requirement: CHAT-001 Ответ только после поиска

chat::ask SHALL искать hybrid, расширять hits соседними репликами и передавать модели нумерованные фрагменты. При успешном поиске без фрагментов ответ «не найдено» возвращается без LLM; отказ поиска подчиняется SEARCH-002. Это один запрос к архиву, не подтверждённая реализация всех scope/потокового диалога из старого F4.

Код: [ask, expand](../../../crates/localvox-light-api/src/chat.rs).
Существующая проверка: `a_hit_is_expanded_into_the_conversation_around_it`.

#### Scenario: Поиск ничего не нашёл

- **WHEN** список фрагментов пуст
- **THEN** модель не вызывается.

#### Scenario: Найден фрагмент

- **WHEN** hit попал на реплику
- **THEN** контекст расширяется соседними строками.

### Requirement: CHAT-002 Ссылки и сомнения ответа

Чат SHALL отбрасывать выдуманные номера цитат, проверять ответ против переданных фрагментов и возвращать verified/ungrounded. При отказе модели несмотря на лексические совпадения выполняется один повтор; если отказ остаётся, найденные фрагменты всё равно показываются. Ссылки сами по себе не доказывают фактическую точность.

Код: [ask, cited, is_refusal](../../../crates/localvox-light-api/src/chat.rs).
Существующая проверка: `citations_are_parsed_and_invented_ones_are_rejected`, `a_refusal_is_a_valid_answer_without_citations`.

#### Scenario: Выдуманная цитата

- **WHEN** ответ сослался на отсутствующий номер
- **THEN** она не попадает в sources.

#### Scenario: Честный отказ

- **WHEN** по смысловым фрагментам модель отказывается отвечать
- **THEN** отказ допускается без требования выдумать цитату.

## Implementation status

SEARCH-002/CHAT-001 нарушены при двух отказах: текущий hybrid возвращает пустой список (RV-008). Живой прогон индексации и отмены остаётся BL-005.

## Observed limitations

BL-005: полный прогон индексации/отмены/поиска не выполнен. Полнота поиска всех заметок, тегов и задач из реестра не обещается. Молчаливое пустое hybrid при двух ошибках — вопрос RV-008. Saved searches, дайджесты и связи записей остаются идеями.
