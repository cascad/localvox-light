# Archive playback Specification

## Purpose

F10/F8. Просмотр, проигрывание, экспорты и удаление записей.

Статус контракта: **accepted**, 2026-09-27. Это обязательное поведение,
а не заявление о безошибочности текущей сборки.
[Основание принятия и границы](../../baseline.md) ·
[Сверка каждого требования](../../evidence/coverage.md#archive-playback).

## Requirements

### Requirement: ARCH-001 Адресация и чтение

Archive SHALL принимать простое имя сессии без обхода каталогов, показывать сохранённые версии и артефакты; transcript читает best и связывает имена/таймкоды с репликами. Путь пользователя не является произвольным путём файловой системы.

Код: [Archive](../../../crates/localvox-light-api/src/archive.rs).
Существующая проверка: `session_dir_rejects_everything_but_plain_names`.

#### Scenario: Path traversal

- **WHEN** в имя сессии переданы разделители/родительский путь
- **THEN** session_dir отклоняет запрос.

#### Scenario: Сводка не удалась

- **WHEN** валидный STT сохранён, а Summary ещё выполняется или завершилась ошибкой
- **THEN** текст доступен для чтения и экспорта, ошибка сводки показана отдельно от готовности текста.

### Requirement: ARCH-002 Один плеер и граница реплики

UI SHALL использовать один audio-элемент: клик по строке задаёт start и until, останавливается у конца реплики; клик по волне/обычный Play снимает ограничение until. Повторный клик по той же строке различается nonce. Диапазон seek ограничивается длительностью.

Код: [Player, SeekRequest](../../../ui/src/Player.tsx).

#### Scenario: Та же реплика дважды

- **WHEN** клик повторён на том же времени
- **THEN** nonce вызывает повторное воспроизведение.

#### Scenario: Продолжение

- **WHEN** после клипа нажата обычная Play
- **THEN** until сбрасывается, воспроизведение продолжается.

### Requirement: ARCH-003 Аудио через чанки

API SHALL строить WAV и поддерживать HTTP Range для плеера, а отдельный clip — извлекать диапазон с точностью сэмплов. source_id выбирает дорожку, отсутствие source означает mix с насыщением; отсутствующая дорожка в смешивании даёт тишину. Нечитаемый пересекающийся чанк в clip даёт ошибку.

Код: [Archive](../../../crates/localvox-light-api/src/archive.rs), [handle_request, respond](../../../crates/localvox-light-api/src/http.rs).
Существующая проверка: `audio_clip_extracts_sample_accurate_range`, `audio_clip_errors_when_overlapping_chunk_unreadable`, `mixing_two_loud_tracks_does_not_wrap_into_noise`.

#### Scenario: Через границу чанков

- **WHEN** clip пересекает два доступных чанка
- **THEN** результат собирается из обоих диапазонов.

#### Scenario: Повреждённый чанк

- **WHEN** нужный clip пересекает нечитаемый чанк
- **THEN** clip возвращает ошибку вместо фиктивного полного звука.

### Requirement: ARCH-004 Экспорт best

export_session SHALL создавать transcript.txt/md/srt из best-версии, использовать speaker либо подпись источника и перезаписывать производный экспорт. Нет best, файла или реплик — ошибка. Это сегментные таймкоды, не обещание пословного karaoke.

Код: [export_session](../../../crates/localvox-light-core/src/export.rs).

#### Scenario: Нет расшифровки

- **WHEN** экспорт запрошен до появления версии
- **THEN** выдаётся ошибка с указанием сначала выполнить STT.

### Requirement: ARCH-005 Явное удаление

delete_session SHALL требовать confirm, равный имени, запрещать удаление активного захвата по .recording_session. Для занятой фоновой обработки система SHALL сначала запросить управляемую остановку и подтвердить освобождение владения, затем исключить повторный захват, удалить задание и каталог сессии (DEC-007). При неудаче остановки файлы SHALL сохраняться с объяснимым отказом. Это окончательное удаление, не корзина и не undo; уже отсутствующая сессия даёт ошибку.

Код: [Archive](../../../crates/localvox-light-api/src/archive.rs).
Существующая проверка: `delete_needs_the_session_name_and_is_final`.

#### Scenario: Нет подтверждения

- **WHEN** confirm не совпал с именем
- **THEN** каталог не удаляется.

#### Scenario: Идёт запись

- **WHEN** имя совпадает с .recording_session
- **THEN** удаление отклоняется.

#### Scenario: Фоновая обработка занята

- **WHEN** подтверждено удаление сессии с активным worker
- **THEN** сначала подтверждается остановка и освобождение сессии; до этого исходники не удаляются, новый worker не получает её.

#### Scenario: Остановка не подтверждена

- **WHEN** worker не освободил сессию
- **THEN** удаление не выполняется, пользователь видит причину.

## Implementation status

ARCH-005 пока отказывает занятому worker вместо управляемой остановки (BL-002). ARCH-001 проверен при failed Summary. Плеер/длинный FLAC в браузере не прогонялись.

## Observed limitations

BL-002 выполнен частично: delete проверяет .worker.lock и сохраняет файлы занятого worker; управляемая остановка перед удалением ещё не реализована. Наличие waveform/таймкодов не подтверждает скорость seek на реальном длинном FLAC. Управление скоростью и пословный плеер из старого реестра не обнаружены в текущем Player.tsx. Text/Summary без аудио проверены по сохранённому транскрипту (BL-007); повтор STT требует исходника. [Текущая сверка](../../evidence/implementation-review-2026-09-27.md).
