# Промоматериалы LocalVox

Готовые оригиналы: [галерея](../docs/promo.md), [PNG/GIF и manifest](../docs/media/).
Кадры сняты с настоящих UI/TUI на вымышленных данных; личных записей здесь нет.

## Референс посадочной страницы

По поручению владельца от 2026-11-21: [GitHub CLI — cli.github.com](https://cli.github.com/).
Использовать как визуальный референс будущей страницы LocalVox и его установщика:
краткая идея продукта, заметная команда установки с выбором ОС и копированием,
демонстрация терминала, затем короткие блоки возможностей. Для LocalVox показать
оба клиента — TUI и GUI — настоящими скриншотами/GIF. Это зафиксированный ориентир
для страницы; сама страница пока не реализована.

это отдельная задача владельца. [Как переснять интерфейсы](../docs/promo.md#переснять).
