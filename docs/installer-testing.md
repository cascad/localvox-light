# Проверить установщик без установки

Из корня репозитория:

**Windows, PowerShell:**

```powershell
.\scripts\test-installer.ps1 -SkipRust
```

**Linux и macOS:**

```bash
bash scripts/test-installer.sh --skip-rust
```

Нужен Python 3.11+; на Windows также используется штатный Windows PowerShell.
Стенд поднимает HTTP только на localhost, создаёт крошечные архивы и подменяет
устанавливаемые программы. Проверяет загрузку, контрольные суммы, выбор платформы,
отказ от опасного архива, повторный запуск без сети и уборку временных файлов.
Настоящие модели, Ollama, пакетные менеджеры, PATH и пользовательский архив не меняет.
Временные файлы находятся в `target/tmp`. Недоступные нативные сценарии помечаются skipped.

Без `-SkipRust` / `--skip-rust` добавляются проверки настроек и реального мастера
с клавишами через ConPTY/PTY: отмена, применение, повтор, возврат назад. Для них
нужны Rust и подготовленная Vosk-библиотека из инструкции разработчика.

Это проверка доставки и поведения мастера. Чистая установка настоящих зависимостей,
разрешения ОС, микрофон и прослушивание проверяются отдельно на каждой ОС.
