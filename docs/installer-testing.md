# Проверить установщик без установки

Из корня репозитория:

**Windows, PowerShell:**

```powershell
.\scripts\test-installer.ps1 -SkipRust
```

**Linux и macOS:**

```bash
bash scripts/test-installer.sh --skip-rust
```

Нужен Python 3.11+; на Windows также используется штатный Windows PowerShell.
Стенд поднимает HTTP только на localhost, создаёт крошечные архивы и подменяет
устанавливаемые программы. Проверяет загрузку, контрольные суммы, выбор платформы,
отказ от опасного архива, повторный запуск без сети и уборку временных файлов.
Настоящие модели, Ollama, пакетные менеджеры, PATH и пользовательский архив не меняет.
Временные файлы находятся в `target/tmp`. Недоступные нативные сценарии помечаются skipped.

Отдельно, с доступом в интернет, до сборки/публикации:

```text
python scripts/check-model-sources.py
```

Проверяет все настоящие URL из `models.json`: HEAD и первые 64 байта через Range,
включая перенаправления, HTTP-отказы, размер и сигнатуру ZIP. Веса не сохраняет;
проверку полного SHA-256 и распаковку это не заменяет. Та же проверка блокирует
сборку в GitHub Actions, если источник недоступен. Основной стенд выше использует
только localhost, внешняя сеть ему не нужна.

На Windows загрузчик в стенде запускается через Windows PowerShell 5, как в
настоящем установщике; кириллица дополнительно проверяется через PS5/PS7 с OEM-консолью.

Без `-SkipRust` / `--skip-rust` добавляются проверки настроек и реального мастера
с клавишами через ConPTY/PTY: отмена, применение, повтор, возврат назад. Для них
нужны Rust и подготовленная Vosk-библиотека из инструкции разработчика.
Также собирается `terminal-capture`: bootstrap проверяется в настоящем терминале
на медленной передаче 2 MiB, с известным/неизвестным размером и отменой `Ctrl+C`.
Если helper уже собран, `SkipRust` использует его без повторной сборки. Для другого
каталога сборки можно явно задать `LOCALVOX_TEST_PTY_RUNNER` — полный путь к helper.
`LOCALVOX_TEST_CAPTURE_DIR` сохраняет ANSI-запись этих тестовых загрузок для просмотра.

Это проверка доставки и поведения мастера. Чистая установка настоящих зависимостей,
разрешения ОС, микрофон и прослушивание проверяются отдельно на каждой ОС.
