# Summit AI Notes — анализ конкурента

> Дата анализа: 2026-07-10. Источники: [summitnotes.app](https://summitnotes.app/),
> [документация](https://summitnotes.app/docs/), [блог](https://summitnotes.app/blog/),
> [release notes 1.1–1.9.1](https://summitnotes.app/docs/release-notes),
> [App Store](https://apps.apple.com/us/app/summit-ai-notes/id6754717420?mt=12).

## Что это

Нативное macOS-приложение (только Apple Silicon, рекомендовано 16 ГБ RAM) для заметок
со встреч. Распространяется через Mac App Store. Темп разработки высокий: с ноября 2025
(v1.1) по июнь 2026 (v1.9.1) — ~14 релизов, примерно два в месяц.

**Монетизация:** $12.99/мес, $89.99/год, $149.99 lifetime; 15 бесплатных записей без
регистрации. Все фичи во всех планах — платят за сам продукт, не за тиры.

**Стек (по release notes):** транскрипция и диаризация — FluidAudio (Swift, локально);
локальные LLM — llama.cpp/GGML + Metal (Qwen3-30B-A3B, GLM-4.7-Flash, Mistral 3, подбор
модели под RAM конкретного Mac); векторный поиск — мультиязычные embeddings.

## Возможности

### Запись
- Микрофон + системный звук на самом Mac → **без ботов в звонке**; работает с Zoom,
  Teams, Meet, Slack и с очными встречами / телефонными разговорами.
- Автодетект звонков (с игнор-листом приложений), автозапись по событиям календаря,
  авто-стоп, управление из menu bar.
- Запись экрана параллельно с аудио; скриншоты и вложения, вклеиваемые в транскрипт
  с таймштампами (1.9–1.9.1).
- Импорт существующих аудио- и видеофайлов (с извлечением дорожки).

### Транскрипция
- Локально, 100+ языков.
- Диаризация спикеров + персистентное тегирование реальными именами (пользователи
  прямо называют это причиной покупки).
- Live-распознавание известных спикеров во время записи (beta в 1.9.1).
- AI-очистка от слов-паразитов и фальстартов.

### Суммаризация (LLM)
- Три режима на выбор пользователя: **встроенный локальный LLM** (модели качаются в
  приложение), **облако** (OpenAI, Anthropic, Gemini, DeepSeek, OpenRouter),
  **self-hosted** (LM Studio, Ollama).
- Кастомные шаблоны («Attention Templates») под типы встреч: стендап, интервью, лекция…
- Action items с исполнителями, дедлайнами и таймштампами; шаг валидации инсайтов
  против галлюцинаций; «shared context» на папке, чтобы серия встреч суммировалась
  с общим контекстом.

### База знаний поверх записей
- Папки (включая вложенные), полнотекстовый + векторный поиск, «похожие документы».
- Чат с одним или многими документами (RAG, стриминг ответов).
- Страница People: профили участников, их action items.

### Интеграции
- Календарь (auto-record, AI-подготовка к предстоящим встречам).
- Apple Reminders (отправка action items с подстановкой исполнителей).
- Автоэкспорт markdown → Obsidian (фильтр по папкам).
- Email-отправка summary, deep links, оффер-коды в App Store.

## Парадигма

1. **Local-first privacy как единственный дифференциатор.** «Ваши звонки не становятся
   training data вендора». Блог целиком построен на юридических рисках облачных
   нотетейкеров: BIPA (голос = биометрия), GDPR ст. 9, HIPAA, дело Brewer v. Otter.ai,
   «почему IT заблокировал Otter». Целевая аудитория — регулируемые профессии: юристы,
   консультанты, финансы, медицина.
2. **No meeting bots.** Захват на устройстве → платформонезависимость, не нужны
   согласия на бота в звонке, работает и для очных встреч.
3. **Записи — не самоцель, а вход в персональную базу знаний.** Поиск, чат, люди,
   Obsidian. Позиционируются против «25 000 минут записей, по которым нельзя искать».
4. **Гибридный AI под контролем пользователя.** Локально по умолчанию, облако — осознанный
   выбор для важных встреч. «Right-sizing AI»: не самая умная модель, а достаточная.

## Куда движется (тренды по релизам 1.6 → 1.9.1)

1. **От транскриптора к рабочему ассистенту**: action items → Apple Reminders с
   автоподстановкой исполнителей, задачи на профилях людей, AI-подготовка к встречам,
   email-рассылка. Закрывают весь цикл встречи, а не только запись.
2. **Realtime и мультимодальность**: live speaker ID (beta), запись экрана, скриншоты
   в таймлайне. Идут к полному контексту встречи, не только аудио.
3. **RAG и знания**: глобальный чат по многим документам, embeddings, shared context.
4. **Гибкость AI-стека**: постоянное добавление провайдеров и свежих локальных моделей.
5. **Комплаенс-нарратив** (BIPA/HIPAA/GDPR) — окучивают регулируемые отрасли, где
   облачные конкуренты юридически токсичны.

## Сравнение с localvox-light

Парадигма совпадает: локальная офлайн-обработка, приватность, mic + loopback без ботов.
Разные стадии и ниши:

| Ось | Summit AI Notes | localvox-light |
|---|---|---|
| Форма | GUI-приложение macOS (App Store, $) | Rust CLI/TUI, три бинарника, Windows-first (WASAPI) |
| ASR | 100+ языков, диаризация, live speaker ID | Vosk ru + GigaAM v3 ONNX (ru, пунктуация); диаризации нет |
| LLM | Суммаризация, action items, чат, шаблоны — локально/облако/self-hosted | Нет (summary для UAT делали внешним LLM вручную) |
| Организация | Папки, full-text + векторный поиск, профили людей | Файлы на диске: `transcript.jsonl` / `.txt` |
| Интеграции | Календарь, Reminders, Obsidian, email | yt-dlp + ffmpeg: YouTube и медиафайлы — **этого у Summit нет** |
| Инженерное ядро | Потребительский продукт (в фиксах: потеря БД, падения) | Durable queue, WAL, crash recovery, at-least-once, backpressure |

**Где мы сильнее:**
- Ingestion произвольных источников: YouTube URL, любые медиафайлы (Summit умеет только
  импорт локальных файлов).
- Надёжность конвейера: переочередь WAV после падения, идемпотентность по `seg_id` —
  у Summit это болело («prevented database loss», «recordings playable after crash»).
- Windows — Summit принципиально mac-only, ниша Windows-корпоратов пуста.
- CLI-скриптуемость и автоматизация.
- Русская специализация: GigaAM v3 даёт пунктуацию и нормализацию чисел для ru.

**Чего не хватает на фоне Summit (gap-анализ):**
- Диаризация спикеров и персистентные имена.
- LLM-пост-обработка: суммаризация, action items (ручные `transcript_uat_processed.md`
  / `transcript_uat_summary.md` в корне репо — прямое свидетельство потребности).
- Шаблоны суммаризации.
- Единый формат вывода realtime- и батч-путей (сейчас `.jsonl` vs `.txt`).
- Экспорт SRT/VTT/markdown (Obsidian).
- Поиск по архиву транскриптов.

**Вывод.** Summit доказывает коммерческую состоятельность нашей парадигмы: люди платят
$150 lifetime именно за «локально, приватно, без ботов». Траектория Summit
(транскрипт → суммаризация → задачи → база знаний) — фактически референсная дорожная
карта надстройки над нашим конвейером. При этом наша ниша (Windows, CLI, YouTube/файлы,
русский язык) Summit'ом не занята. См. `docs/feature-backlog.md`.
