# Реестр фич — зафиксировано 2026-07-11

> Канонический список того, что строим. История обсуждений и детали — в
> `feature-backlog.md` (реестр ссылается на его разделы), исполнение — в
> `work-plan.md`. Изменение реестра — только через журнал решений бэклога.

## Принципы (P)

| ID | Принцип |
|---|---|
| P1 | **Durability**: WAL/append-only, at-least-once, crash recovery — не регрессировать |
| P2 | **Первичные данные неприкосновенны**: каждая обработка = новая версия рядом, с манифестом; перелистывание версий; указатель best |
| P3 | **Аудио**: retention-политика N дней (FLAC после закрытия чанка), удаление только по политике или явной команде |
| P4 | **Модульность**: всё, кроме ядра, — отключаемые модули (cargo features + runtime-конфиг) |
| P5 | **Отчуждаемость**: модули работают только с файлами сессии — выносимы в отдельные процессы |
| P6 | **Двухскоростной конвейер**: slow lane — основной путь качества (бюджет: час сессии ≤ 5 мин варки); fast lane — только wake-word, мемо, опциональная live-индикация |
| P7 | **UI — отделяемый слой**: ядро-библиотека + событийная шина + локальный API; TUI/GUI/PWA — клиенты |
| P8 | **Без облака по умолчанию**: любые облачные вызовы — явный opt-in (LLM-профили); никакого нашего облака/релея |
| P9 | **БД (sqlite или аналог) — только индексация и мета**; файлы — источник истины; аудио в БД — никогда; всё в БД пересоздаваемо из файлов |

## Инфраструктура (зафиксировано)

- **Хранение**: файлы сессии (чанки FLAC, `transcripts/v*.jsonl`, `versions.json`,
  `processed.md`, `summary.md`, `meta.json`) + `meta.sqlite` только для
  индексов/меты (P9).
- **Кроссплатформа**: ядро/TUI/CLI — win/mac/linux; захват system audio: WASAPI
  (есть) / ScreenCaptureKit / PipeWire; трей — все три ОС.
- **Стек моделей**: см. `local-models.md` (GigaAM v3, Silero VAD, Piper, bge-m3,
  sherpa-onnx диаризация — всё на ort; LLM через Ollama/OpenAI-compatible).
