# ADR-0003: штатный workflow и официальные OpenSpec skills

2026-09-27. Организация работы изменена по прямому запросу владельца.
[ADR-0002](0002-openspec-code-inventory.md) сохраняет правило инвентаризации по коду
и последующего принятия capability; этот ADR уточняет ведение открытых изменений.

OpenSpec CLI 1.13.2 установлен вместе с интеграцией Codex, сгенерированной через
`openspec init --tools codex`. Используются девять официальных skills без правки их
текста. Проектные ограничения остаются в AGENTS.md и openspec/config.yaml.

Конкретная работа живёт в `openspec/changes/<name>`, создаваемой через CLI.
Состояние артефактов читаем через `status`, шаблоны и зависимости — через `instructions`,
реализацию — через tasks.md и `instructions apply`. Бэклог перестаёт быть вторым
местом ведения тех же задач: в нём только ссылки BL-ID и ещё не разобранные группы идей.
Catalog/review/evidence остаются вспомогательными документами, а не заменой workflow.

Для неопределённой работы допустим proposal-only change. Отсутствие delta, design
и tasks не маскируется фиктивными файлами. `skip_specs` используется лишь для scope,
который не меняет поведение продукта: измерения, исследования, документация и инструменты.
Валидатор законченного change не заменяет проверку готовности частичного планирования.

Переход переносит 12 конкретных BL-записей в 12 change-пакетов: три существовавших
и девять новых черновиков. Семь групп BL-011–017 остаются в inbox. Исходные сведения,
пользовательские примеры и критерии сохранены; решения о реализации не выдумываются.
Никакие runtime-функции этим переносом не реализованы, baseline не принят и не синхронизирован.

Свидетельства установки, проверки и ограничения — в
[отчёте перехода](../../openspec/evidence/native-workflow.md).
