# Пользовательские сценарии (2026-07-11)

> Сценарии — от лица основного пользователя (инженер/лид на Windows, встречи в
> Zoom/Teams, знания в Obsidian, русский язык). Каждый сценарий: триггер → как это
> выглядит → что требуется (фичи из `feature-backlog.md`) → статус.
> Фазы: A (LLM-фундамент), B (интерактив), C (ambient), D (паритет и рост).

## S1. Рабочая встреча под запись

**Триггер:** начинается созвон в Zoom/Teams.
**Как выглядит:** ассистент пишет микрофон + системный звук; после встречи сам
прогоняет транскрипт через глоссарий и LLM → `processed.md` (термины починены,
речь причёсана) и `summary.md` (решения, action items, открытые вопросы) →
summary падает в Obsidian-слот.
**Нужно:** ядро (есть) + F1 (LLM + глоссарий) + слот-файл (F2, часть).
**Статус:** сегодня — транскрипт пишется (запуск вручную), суммаризация руками во
внешнем LLM. Полностью оживает в фазе **A** (+автозапуск в C).

## S2. «Запиши» — голосовая заметка на лету

**Триггер:** посреди работы/встречи пришла мысль.
**Как выглядит:** говорю «запиши в идеи: попробовать tantivy для поиска» —
ассистент кладёт заметку в слот «идеи» (Obsidian, шаблон: заголовок+суть+теги)
и проговаривает: «Записал в идеи…». Вариант без адреса — в дефолтный слот.
**Нужно:** F2 (wake-word в партиалах, слоты, TTS).
**Статус:** фаза **B**.

## S3. «Запиши это» — ретро-захват чужой мысли

**Триггер:** на встрече прозвучало важное, повторять вслух неудобно.
**Как выглядит:** говорю «запиши это» — ассистент берёт последние ~30 секунд из
ring-буфера, LLM выжимает суть, кладёт в слот и тихо подтверждает.
**Нужно:** F2 + ring buffer (F3, часть) + F1.
**Статус:** фаза **B** (ring buffer вытаскиваем раньше остального ambient).

## S4. Конспект YouTube-доклада / подкаста / файла

**Триггер:** увидел часовой доклад, смотреть некогда.
**Как выглядит:** `localvox-asr <url> --template конспект` → через несколько минут
в Obsidian конспект с таймкодами и главными тезисами. То же — с любым локальным
видео/аудио; папка-вотчер: кинул файл — получил конспект.
**Нужно:** ingest (есть) + GigaAM (есть) + F1 (шаблон «конспект»); watch-folder —
идея-пул.
**Статус:** транскрипт — уже работает; конспект — фаза **A**. Уникальная фича,
у конкурентов нет.

## S5. «Что мы решили?» — поиск по архиву

**Триггер:** спор через две недели: «а что мы решили по retention?»
**Как выглядит:** `localvox search "retention"` или панель в TUI → сегменты с
контекстом, рядом ссылка на summary той встречи. Позже — семантически: «что мы
решили про хранение аудио» находит и без точного слова, а «чат с базой» отвечает
цитатами.
**Нужно:** F4 этап 1 (tantivy) → этап 2 (embeddings) → этап 3 (RAG).
**Статус:** фаза **B** (full-text), **C** (семантика), **D** (чат).

## S6. День на автопилоте (ambient-секретарь)

**Триггер:** просто включил компьютер утром.
**Как выглядит:** демон висит в трее (win/mac/linux); созвон начался — сам понял
(WASAPI-сессии zoom.exe) и записал с pre-roll; между встречами наловил голосовых
заметок; вечером — дайджест: «3 встречи, 7 action items, 2 заметки; ты обещал
скинуть артефакты и посмотреть подсказку на дизайне». Hotkey-пауза в любой момент;
аудио старше N дней чистится само.
**Нужно:** F3 целиком + F1 + retention-sweeper; дайджест — идея-пул.
**Статус:** фаза **C**.

## S7. Телефон: найти и надиктовать

**Триггер:** в дороге вспомнил про договорённость / пришла мысль.
**Как выглядит:** ярус 0 — открыл Obsidian mobile (vault синкается) → нашёл summary.
Ярус 1 — открыл PWA (через Tailscale) → поиск по всему архиву, чат с базой.
Ярус 2 — надиктовал мысль в приложение; дома телефон синканулся, заметка прошла
общий конвейер и легла в слот.
**Нужно:** F7 (ярусы 0/1/2), F6 для яруса 1.
**Статус:** ярус 0 — фаза **B** (бесплатно, следствие слотов-файлов), ярус 1 —
фаза **C**, ярус 2 — фаза **D**.

## S8. Внешний агент работает с моим архивом (MCP)

**Триггер:** пишу код в Claude Code, нужен контекст прошлых обсуждений.
**Как выглядит:** агент через MCP-сервер localvox вызывает
`search_transcripts("дизайн API слотов")`, получает выдержки и summary, использует
в работе; может и `append_note` — положить вывод в мой слот.
**Нужно:** F6 (MCP-сервер) + F4.
**Статус:** фаза **C**.

## S9. UAT/демо: протокол из хаоса (реальный прецедент)

**Триггер:** провёл UAT-демо с командой (наш `transcript_uat.txt`).
**Как выглядит:** после встречи — `processed.md` (термины: «капаштет» → capacity,
«кант» → Гант; реплики разложены по ролям) и `summary.md` (решения, баги, открытые
вопросы, договорённости «допилить и скинуть артефакты»).
**Нужно:** F1 + глоссарий (seed уже есть из этого же UAT); роли — позже диаризация (D).
**Статус:** сделано один раз руками — становится автоматикой в фазе **A**.

## S10. Чувствительная встреча (приватный режим)

**Триггер:** обсуждение зарплат/оргвопросов или NDA-клиента.
**Как выглядит:** сессия помечена приватной: LLM — только локальный профиль
(облачный запрещён политикой сессии/слота), summary в зашифрованный слот, аудио —
короткий retention или сразу в корзину, hotkey-mute работает мгновенно.
**Нужно:** F1 (профили per-задача — уже заложено) + политика per-session +
шифрование at rest (идея-пул).
**Статус:** частично фаза **A** (профили), полностью — **D**. Усиливает наш
privacy-нарратив.

## S11. Ретро/1:1 с аналитикой (после диаризации)

**Триггер:** после ретро интересно, как прошло.
**Как выглядит:** talk-time по участникам, кто какие темы поднимал, обещания по
людям (People-профили): «Саша дважды обещал написать тест-план».
**Нужно:** диаризация + идеи-пул (talk-time, People).
**Статус:** фаза **D**.
