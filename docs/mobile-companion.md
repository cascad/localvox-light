# Мобильный доступ (F7) — разбор вариантов

> Заявка владельца (2026-07-10): «подумать над мобильным приложением, хотя бы доступ
> к поиску по базе записей». Принцип: без нашего облака — телефон говорит с твоим же
> десктопом.

## Цели и не-цели

**Минимум (обязательный):** поиск по базе записей с телефона.
**Желательно:** чтение summary/транскриптов, чат с базой, дайджест/уведомления,
захват голоса на ходу.
**Не-цели:** наш облачный аккаунт/релей, транскрипция на телефоне (пока), синк
между «чужими» устройствами.

## Ярус 0 — без единой строчки кода (доступен с фазы B)

Слоты-файлы и summary уже лежат markdown'ом. Если слот-папка = Obsidian vault:

- **Obsidian mobile** + синк на выбор пользователя (Syncthing — локально и бесплатно;
  либо его iCloud/Drive) → поиск и чтение заметок и summary на телефоне.
- Ничего не пишем, ничего не поддерживаем. Ограничение: ищется только markdown
  (заметки, summary), не весь jsonl-архив.

**Вывод:** закрывает 60% потребности бесплатно; продаётся как фича «Obsidian-нативность».

## Ярус 1 — PWA поверх демона (фаза C, рекомендованный основной путь)

Демон уже держит локальный API (F6). Добавляем к нему статическую веб-страницу
(PWA): демон отдаёт `GET /` → лёгкий UI.

- **Функции:** поиск по всему архиву (tantivy), чтение транскриптов/summary,
  чат с базой (RAG через десктопный LLM), статус записи, пауза/mute.
- **Доступ из LAN:** `http://desktop.local:port` + токен.
- **Вне дома:** Tailscale/WireGuard (пользовательский, не наш) — телефон видит
  десктоп как локальный хост. Документируем как рекомендованный путь; никакого
  нашего релея.
- **Безопасность:** API слушает localhost по умолчанию; выставление на LAN —
  явная опция + токен; TLS через self-signed или Tailscale (у них есть HTTPS).
- **Плюсы:** нет app store, нет второй кодовой базы, работает на любом телефоне,
  автоматически апгрейдится вместе с демоном.
- **Минусы:** нужен включённый десктоп; нет фонового захвата на телефоне;
  push-уведомления у PWA ограничены (iOS — особенно).

## Ярус 2 — нативное приложение (фаза D, по потребности)

Когда/если понадобится захват на ходу и нормальные уведомления.

- **Технология:** Tauri 2 mobile (Android/iOS) — переиспользуем Rust-ядро и типы;
  альтернатива — Flutter/React Native как чистый клиент API.
- **Захват на телефоне:** диктофон → локальная очередь на телефоне (те же принципы:
  durable, uuid v7 для дедупа) → синк на десктоп, когда доступен → общий конвейер
  ASR/LLM. Телефон = ещё один источник (`source_id`), не отдельный мир.
- **Уведомления:** дайджест дня, action items — локальные нотификации приложения;
  опция для энтузиастов — self-hosted ntfy.
- **Позже (опционально):** on-device мини-ASR для черновой расшифровки без десктопа.
