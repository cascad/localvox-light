# Терминалы: проверка ввода

TUI использует общие клавиши и bracketed paste, без настроек под имя терминала.
Вставка — сочетанием самого терминала; если `Ctrl+V` получает приложение, оно
вставляет текст из буфера. Для терминала без границ вставки сначала открыть поле
через `i`. Проверка ниже нужна один раз после изменения чтения ввода.

1. В списке и в документе вставить `https://example.org/qri:Русский🦀`.
   Открывается заполненный «Импорт», приложение не закрывается. Нажать `Esc`:
   импорт не начинается.
2. `i` → вставить ту же ссылку: всё значение сохранено, ничего не отправлено.
   `Esc`. Затем `/` в списке → вставить `Русский🦀`: меняется только фильтр.
   `Esc` очищает его. Проверить многострочный текст через форму вопроса.
3. Проверить стрелки, `j/k`, `Page Up/Down`, `Tab`/`Shift+Tab`, `F6`, `Alt+←/→`.
   В RU-раскладке `/` и `g` по прежним позициям клавиш. Менять размер окна.
4. Закрыть через `F10` и снова запустить: обычный ввод/вставка терминала работают.
   `F8/F9` проверять только при намеренной записи; это действия записи/остановки.

Матрица на 2026-11-11. `not-run` означает отсутствие реального прогона этого
эмулятора, а не запрет поддержки. Тест ConPTY не заменяет проверку его host UI.
