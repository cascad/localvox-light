# Что можно сделать в LocalVox

Короткий справочник пользовательских сценариев. UI — браузер или окно приложения;
TUI — терминальный клиент. Сначала [запустите приложение и настройте модели](../README.md#как-запустить).
Ниже описано ожидаемое поведение функций; результаты проверок и известные разрывы —
в [OpenSpec](../openspec/README.md). Историческое видение S1–S11 — [отдельно](user-scenarios.md).

[Как вручную проверить текущую сборку UI/TUI](manual-acceptance.md): порядок действий, ожидаемый результат и отметки прогона.

В TUI нажмите `:` и выберите команду стрелками и `Enter`; в таблицах приведены её
точные названия. `?` открывает справку, `Esc` закрывает форму, `Ctrl+Enter` отправляет
её (`Ctrl+S` — запасной вариант). Ссылка, настройка и переход ко времени подтверждаются
обычным `Enter`. `Tab` меняет область, `↑/↓` выбирают строку,
`←/→` — вкладку документа. Эти клавиши действуют вне редактирования полей.

## Запись и обработка

| ID · Задача | Что сделать | Что должно произойти |
|---|---|---|
| US-001 · Записать встречу | UI: «Запись» в верхней строке. TUI: «Начать запись», ввести название. | Начнётся запись настроенных источников звука; видны активная запись и время. При включённом pre-roll в неё войдёт предшествующий звук. |
| US-002 · Закончить встречу | UI: «Стоп». TUI: «Остановить запись». | Аудио закроется, запись появится в архиве и очереди распознавания. Остановить можно и пока начало ещё подтверждается. |
| US-003 · Разделить встречи | UI/TUI: остановить текущую запись, затем начать следующую с новым названием. | Первая встреча закроется для обработки, следующая сохранится отдельно. |
| US-004 · Расшифровать ссылку | UI: вставить HTTP(S)-ссылку в поиск → «Расшифровать по ссылке» или вставить вне текстового поля. TUI: `i` / «Импорт URL» → вставить ссылку YouTube или другого источника → `Enter`. | Запись появится в архиве; «Ход» покажет скачивание, подготовку аудио и распознавание. Сама вставка ещё не запускает импорт. |
| US-005 · Обойтись без долгой постобработки | UI: «Настройки → После распознавания», выключить summary и сохранить. TUI: изменить ту же настройку и «Сохранить изменённые настройки». | Распознавание обязательно; автоматических очистителей нет. Уже идущий LLM-этап завершится, ещё не начатая summary будет пропущена. «Текст» доступен из исходной расшифровки. |
| US-006 · Понять, что происходит | UI: открыть «Очередь» или верхний индикатор → запись → «Ход». TUI: «Очередь», выбрать задание; в архиве — вкладка «Ход». | Видны текущая фаза, прошедшее время, предыдущие длительности и следующие шаги. Ожидание, backoff, отсутствие координатора и неизвестные времена подписаны отдельно. |
| US-007 · Прочитать технический журнал | В «Ход» раскрыть `+ N lines`. TUI: `Enter` раскрывает операцию, `o` загружает предыдущие события, `/` задаёт фильтр; `I` раскрывает сведения о записи в начале. | Видны операции, длительности и приглушённые подробности. Новые события не уводят от чтения старых; сбой этапа отмечен, его причина — в консоли TUI (`~`). Сведения по умолчанию свёрнуты. |
| US-008 · Возобновить остановленный этап | UI: «Повторить этап» после ошибки или «Продолжить обработку» после отмены. TUI: выбрать задание → `R` / «Повторить или продолжить этап». | Возобновится та же незавершённая фаза с новым бюджетом попытки. Готовые результаты и история сохранятся. |
| US-009 · Дождаться автоматического повтора | После ошибки открыть очередь. | Видны причина, число попыток и «не раньше». Ограниченные автоматические возвраты идут через 1/2/4 часа; исчерпание требует ручного повтора. Недоступный координатор не выглядит работающим. |
| US-010 · Пережить временный отказ сохранения | Оставить приложение работающим, проверить «Ход». | Запуск/восстановление ждут сохранения очереди. Сохранение результата или ошибки повторяется отдельной операцией журнала без повторного распознавания/LLM и расхода попытки; остановка приложения прерывает ожидание. |
| US-047 · Отменить обработку | UI: «Отменить обработку» в записи или очереди. TUI: выбрать задание → `X` / «Отменить обработку». | После подтверждённой остановки готовый текст остаётся доступен; автоматического продолжения нет даже после перезапуска. Внешняя LLM может ещё заканчивать свой запрос. |

## Архив, текст и звук

| US-012 · Забрать весь текст | UI: «Текст» → «Копировать» или `Ctrl+Shift+C`. TUI: `3` («Текст») → `y` / `Ctrl+Y` / «Копировать документ». | Скопируется весь текст, включая невидимую часть, без таймкодов и имён говорящих. Без очистки это единый исходный текст, без дополнительного вызова модели. |
| US-013 · Скопировать другой документ | Открыть нужный документ → UI: «Копировать»; TUI: «Копировать документ». | В буфере окажется документ без управляющих элементов. В TUI «Сохранить документ» записывает его по новому пути; существующий файл не перезаписывается, нужно выбрать другой путь. |
| US-014 · Сверить реплику со звуком | UI: «Реплики» → кнопка прослушивания строки. TUI: выбрать реплику → `p` / «Слушать фрагмент». | Плеер проиграет соответствующий фрагмент до его конца и остановится. Текст и позиция связаны с одной записью. |
| US-015 · Управлять прослушиванием | UI: play/pause, шкала, кнопки ±15 с. TUI: `Space`, `Alt+←/→`; `g` → часы/минуты/секунды → `Enter`. `Tab` меняет поле, `↑/↓` — число. | Время ограничено длительностью записи, минуты/секунды — 0–59. `F6` даёт фокус плееру: `←/→` ±5 с (`Shift` — 30 с), `Home/End` — начало/конец. Для звука в TUI нужен mpv; причина сбоя — в консоли ошибок. |
| US-016 · Переключить запись во время прослушивания | Выбрать другую запись или уйти из архива. | Старый звук остановится. Обновление длительности той же записи сохраняет позицию и паузу; пропавшее аудио не мешает читать текст. |
| US-017 · Проверить сводку по источнику | UI: нажать таймкод/ссылку фрагмента в сводке. TUI: выбрать источник документа → «Слушать фрагмент». | Откроется соответствующий участок звука. Пометка сомнений остаётся до проверки; подтверждение не исправляет текст автоматически. |
| US-018 · Подтвердить проверенный документ | UI: в документе с предупреждением нажать подтверждение. TUI: «Подтвердить документ». | Сохранится подтверждение текущего результата. Отсутствующий или повреждённый файл не становится исправным от подтверждения. |
| US-019 · Выбрать рабочую версию | UI: «Реплики» → список версий. TUI: «Выбрать версию», ввести ID. | Выбранная версия станет рабочей для чтения и следующих операций. Остальные версии сохранятся; новая сводка сама от переключения не создаётся. |
| US-020 · Изменить язык записи | UI: «Реплики → Язык», подтвердить переработку. TUI: «Изменить язык», ввести код или `auto`. | Начнётся полная переработка с выбранным языком; нужны исходное аудио и его модель. Ошибка постановки в очередь не должна выдавать успешную смену. |
| US-021 · Подписать участников | UI: «Участники» → переименовать. TUI: выбрать участника → «Имя участника»; отдельная команда «Имя источника» подписывает канал. | Имя действует в этой записи, текст и времена реплик сохраняются. Между встречами люди автоматически не узнаются. |
| US-022 · Пересоздать результат | UI: открыть сводку/текст/реплики → «Переварить», подтвердить. TUI: «Повторить сводку», «Повторить текст» или «Повторить всё». | Выбранный scope попадает в очередь. Сводка/текст могут обрабатываться по сохранённому транскрипту без аудио; полный повтор требует аудио. Занятая worker запись отклоняет конфликтующую операцию. |
| US-023 · Удалить запись | UI: корзина у записи и подтверждение. TUI: «Удалить запись», ввести `ДА`. | Запись удалится вместе с её звуком и результатами. Управляемая обработка сначала остановится, затем запись удалится. При неподтверждённой остановке или работе стороннего CLI файлы останутся на месте; ошибка объяснит причину. |

## Голос и дополнительные входы

Нужны запущенный движок, включённый голосовой модуль и настроенные назначения.
Команды ниже — исходные; их можно изменить в конфигурации. Они принимаются с микрофона.

| ID · Задача | Что сделать | Что должно произойти |
|---|---|---|
| US-031 · Надиктовать мысль | Сказать «запиши в идеи …» или «запиши …» для слота по умолчанию; закончить «всё»/«стоп» либо паузой. | Диктовка закончится и будет передана в слот; в UI видны слушание/диктовка/результат. Голосовое подтверждение само по себе не является квитанцией доставки — это известный разрыв. |
| US-032 · Сохранить недавно прозвучавшее | Сказать «запиши это», при необходимости назвать слот. | В заметку попадёт доступный недавний контекст разговора. При пустом буфере приложение сообщит, что сохранять нечего. |
| US-033 · Управлять голосом встречей и ссылкой | «Начни встречу [название]»; отдельно — «возьми ссылку» с HTTP(S)-адресом в буфере обмена. | Первая команда начинает отдельную встречу, вторая отправляет ссылку на обработку. Это не текст обычной заметки. |
| US-034 · Передать локальное аудио/видео | В терминале: `localvox-process --ingest <путь-к-файлу>`. | Материал импортируется для распознавания. В UI/TUI импорт встречи по локальному файлу отдельной кнопкой пока не предусмотрен; «Спросить → файл» работает с текстом. |
| US-035 · Работать через внешние инструменты | Для агента добавить stdio MCP-сервер `localvox-mcp --work-dir <архив>`; для заметок настроить [файловый/MCP-слот](integrations.md). | Агент сможет искать, читать записи/сводки и добавлять заметки; назначение принимает заметки. Это настройка интеграции, а не отдельная кнопка UI. |

## Настройки, подключение и выход

| ID · Задача | Что сделать | Что должно произойти |
|---|---|---|
| US-036 · Изменить параметры | UI: «Настройки» → изменить → «Сохранить». TUI: основные настройки → `Enter` → выбрать/ввести → `Enter`, затем `S` сохранить. `A` показывает все параметры. | Значение отделено от подсказки; переключатели, устройства и провайдеры выбираются из списка. «По умолчанию» убирает явное значение. Удаление старого аудио по сроку включается отдельно; по умолчанию оно выключено. Текст после очистки аудио сохраняется. |
| US-038 · Подключиться с токеном | UI: «Настройки → Подключение этого браузера» → токен → «Подключиться». TUI: «Подключение и токен», указать URL/токен. | Клиент подключится к выбранному серверу. Очистка токена клиента не меняет токен демона; сохранённые секреты не показываются открытым текстом. |
| US-039 · Выбрать оформление | UI: кнопка темы в верхней строке. TUI: «Светлая / тёмная тема», «ASCII / Unicode», «Без цвета / цвет», «16 цветов / true color». | Изменится оформление, функции останутся доступны; текстовый режим подходит терминалам с ограниченными цветами/символами. |
| US-040 · Восстановиться после ошибки связи | Дождаться восстановления API; TUI: при необходимости «Обновить» (`r`) или «Восстановить черновик после ошибки». | Последние данные остаются с пометкой недоступности, после успешного чтения обновляются. Неподтверждённая команда не изображается успешной. |
| US-041 · Закрыть терминальный клиент | Вне формы нажать `q`/`й`; `F10` или `Ctrl+Q` — дополнительные варианты. | TUI закроется и восстановит терминал; работающий демон и запись продолжат работу. Во время ввода обычная `q` остаётся буквой. |
| US-042 · Открыть окно или файлы из трея | Windows, меню значка: «Открыть интерфейс» / «Открыть папку архива». | Откроется окно приложения или папка в Проводнике. Пункт интерфейса доступен при запущенном API. |
| US-043 · Приостановить запись аудио | В трее выбрать «Пауза», затем «Продолжить запись». | Запись аудио приостановится и возобновится. Это управление записью; голосовой модуль настраивается отдельно. |
| US-044 · Запускать при входе в Windows | В трее переключить «Автозапуск при входе». | Пункт покажет включение/выключение запуска приложения при следующем входе. |
| US-045 · Остановить всё приложение | В трее выбрать «Выход»; при обычном консольном запуске — `Ctrl+C`. | Остановятся демон, захват и принадлежащие ему обработчики. Незавершённые задания останутся для восстановления при следующем запуске. |

| US-048 · Посмотреть ошибки TUI | Нажать `~` / `ё` вне формы или `F12` отовсюду. `Tab` выбирает запись, `Enter` раскрывает повторы, `y` копирует журнал; `Esc` закрывает. | Видны время, операция, сессия и известный этап. Одинаковые сбои свёрнуты в `+ N повторов`. Открытие гасит индикатор; тот же продолжающийся сбой не зажигает его снова. История хранится до закрытия TUI. |

Автоматический ремонт любого старого результата пока не реализован. Автодетект всех встреч, мобильная запись и аналитика людей
из исторических планов не считаются готовыми функциями этого справочника.
