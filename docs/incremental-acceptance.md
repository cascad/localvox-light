# Проверка ранней расшифровки в UI и TUI

Кандидат от 2026-11-10. Ближайшая граница: просмотр → список багов → исправления;
общий рефакторинг отдельно. Ранняя LLM-правка в этот выпуск не входит.

## Запуск

Демон, worker и TUI собраны вместе с актуальным UI. Заверши прежнюю запись и выйди
из старого демона через трей, затем из корня проекта:

```powershell
.\target\release\localvox-light.exe --daemon --audio-dir "$PWD\target\uat-incremental"
```

UI: **http://127.0.0.1:3017/**. Во втором PowerShell из корня:

```powershell
.\target\release\localvox-tui.exe --address http://127.0.0.1:3017
```

Используй свой адрес/токен, если они настроены. Архив здесь отдельный, настройки
общие. Если нужна пересборка или установка mpv — [подготовка](manual-acceptance.md#1-подготовить-сборку-и-тестовый-архив).
После проверки верни изменённые настройки.

## Что проверить

1. В UI или TUI: **Настройки → Автоварка → Распознавать во время записи → включить**,
   сохранить. Автоварка должна быть включена; summary для этой проверки выключить.
2. Начать тестовую запись с микрофоном и системным звуком. Говорить и воспроизводить
   речь через выбранный выход. Первый текст ожидается после закрытия файла
   **примерно через 5 минут**, затем ещё нужно время распознавания. Если от одной
   дорожки вообще нет пакетов, общая готовая часть может ждать Stop.
3. Не останавливая запись, открыть **Реплики**, затем **Текст** в обоих клиентах.
   Читать, выделить старый фрагмент и дождаться следующего дополнения (ещё около
   5 минут). Выделение/прокрутка/выбор не должны прыгнуть. Полный доступный текст:
   UI `Ctrl+Shift+C`; TUI `y` или `Ctrl+Y`. Вставить и проверить начало/конец.
4. Запустить старую реплику: UI `▶`, TUI `p`; пауза — `Space`. При дополнении
   звук/позиция/волна сами не меняются. Новое аудио: UI кнопка `+ время` или новая
   реплика; TUI `p` на новой реплике. Переход не должен запускать чужой фрагмент.
5. Во вкладке **Ход** видны готовая граница, работающая порция или ожидание новых
   кусков; ожидание не выглядит завершением всей записи. Нажать **Stop** (TUI `F8`):
   запись заканчивается, хвост обрабатывается, появляется полный результат.
6. На другой тестовой записи отменить **обработку**, продолжить говорить, затем
   Stop. Запись звука продолжается, готовый текст остаётся, обработка сама не
   возобновляется. Явное **Продолжить обработку** / `R` в очереди TUI завершает её.

| Ручной сценарий | Статус |
|---|---|
| Длительный microphone/loopback, стыки и отзывчивость | not-run |
| Реальный звук/пауза/новый снимок в обоих клиентах | not-run |
| Слабый Mac | not-run |

Для бага достаточно: UI или TUI, действие, ожидание, фактический результат,
ID тестовой записи и время/этап из журнала. Прикладывать личную встречу не нужно.

## Известная цена режима

На публичной записи 1 ч 59 мин результат совпал с обычной обработкой; Stop→готово
сократилось с 75–84 до 7–13 секунд. Суммарная активная работа выросла на **48%**,
инженерный лимит 20% не пройден, поэтому предустановка остаётся выключенной.
Это измерение данного Windows/CPU стенда, не обещание для твоих устройств.
