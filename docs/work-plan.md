**WP-C13. Пакет хвостов: код готов 2026-07-12** (живая приёмка — чек-лист).
Семь закрытых хвостов из разных WP: (1) **recovery → meta** — восстановленный
после падения чанк дописывается в `meta.chunks` (offset = конец предыдущего

встречу через полночь не режем) (WP-C6); (3) **семантический индекс по
summary/processed** — «найти по смыслу» работает и по протоколам, не только по
сырым репликам; ключ свежести — mtime производных (WP-C11); (4) **▶ прямо в
выдаче поиска** — «нашёл → послушал» без захода в сессию, с фолбэком на второй
источник (WP-C8); (5) **`GET /api/jobs`** + строка «⚙ варится …» в вебе —
видимость автопилота (WP-C7); (6) **PWA-манифест** — установка веб-архива на
домашний экран телефона (F7); (7) **раздельные exit-коды** варки (1) и
пост-обработки (2): упавший LLM больше не выглядит как провал варки — демон

Ревью (9 агентов, 7 находок, 1 отклонена) — исправлено: восстановленный чанк
из СЕРЕДИНЫ таймлайна вставал в конец (offset считался как max по ВСЕМ чанкам
источника → все клипы после него уезжали) → offset по чанкам с меньшим SEQ +

в meta» при старте; суточный разрез резал только что открытую после полуночи
сессию (day штамповался при разрезе, а не при открытии); hybrid показывал
md-абзац дважды (каналы форматировали сниппет по-разному → дедуп не срабатывал)

**WP-C14. Окна варки + диагностика уровня: код готов 2026-07-12** (найдено на
живой приёмке). Дефолт окон ASR 180/150 с → **30/15 с**: на приёмке разговорная
речь (речь редкая, разрежена паузами) превращалась в кашу, при этом на лекции
длинные окна ещё и теряли текст. Окна из чистой тишины больше не отдаются в
модель (GigaAM на них галлюцинировал «.» и обрывки), но длительность их
по-прежнему двигает таймлайн — иначе уехали бы таймкоды. По просьбе владельца в
`meta.json` каждый чанк получил **`rms`** (средний уровень, 0..32767) и
**`voice_ratio`** (доля 100-мс окон со звуком): теперь «почему плохо
распозналось» видно по мете, без переслушивания — тихий микрофон отличается от
пустой комнаты одним взглядом.

**WP-C15. Бенчмарк качества `localvox-bench`: код готов 2026-07-12.** Регрессию
окон мы поймали **случайно, на слух** — это и есть главный вывод WP-C14. Крейт
`localvox-light-bench` заменяет «на слух» на число: WER/CER на эталонных наборах
(Golos crowd/farfield, Russian LibriSpeech — те же, на которых публикуют WER
авторы GigaAM), скачивание одной командой (`fetch`, datasets-server HF, без
python и токенов), свип по параметрам окон (`sweep`) и **сборка long-form
наборов** (`longform`) — режима, которого в публичных датасетах нет, а у нас он
основной. Подробности и измеренные числа — `docs/asr-bench.md`.
Ключевые результаты: старый дефолт 180/150 на разговорной речи даёт **WER 93 %**
(вот она, «каша»), 30/15 — 7.3 %; на коротких командах Vosk ru-0.42 точнее
GigaAM (3.0 % против 7.7 %), но в 10 раз медленнее. Отдельная находка метрологии:
без разворота числительных («2013» → «две тысячи тринадцать») WER завышался
почти вдвое — модель слышала верно, расходился формат.

Ревью WP-C14/C15 (31 агент, 6 подтверждённых находок) — исправлено:
(1) **смена окон не доезжала до архива** — варка пропускалась по совпадению
метки (`gigaam-int8`), а автоварка считала сваренной любую сессию с best-версией:
весь уже сваренный архив навсегда остался бы на 180/150 c. Введён **рецепт
варки** (`versions::cook_recipe` = метка + окна + порог тишины) в `params`
версии: сессия, сваренная другим рецептом, переваривается ровно один раз
(`JobQueue::requeue_stale` пробивает дедуп по имени сессии, `cook` переставляет
`best` на свежую варку — иначе поиск и экспорт продолжали бы отдавать «кашу»
через refined-версию, построенную от старой). Выключатель —
`LOCALVOX_LIGHT_AUTOCOOK_RECOOK_STALE=0`.
(2) **утечка метрик между чанками**: `LevelStats` кормился до открытия файла и
сбрасывался только на успешной финализации — чанк, который не открылся (диск,
антивирус), утаскивал свой уровень в следующий, и тишина отчитывалась громкой
речью. Ровно инверсия смысла поля. Теперь уровень считается только по сэмплам,
реально легшим в файл, а накопитель забирается безусловно при закрытии чанка.

**WP-C16. Честность LLM: код готов 2026-07-12** (живая приёмка — блокер).
Секретарь выдумал встречу: на сессии с напеванием (расшифровка — «Т.») qwen3.5:4b
собрала протокол с темами, решениями и поручениями «Ивану» и «Марии» — целиком из
нашего же глоссария, который подставлялся в промпт ЦЕЛИКОМ при пустой расшифровке.

Первой заплаткой был порог по числу слов («мало речи → не звать LLM»). Владелец её
забраковал, и правильно: она защищает от тишины ценой короткой мысли и пятиминутного
звонка — ровно того, ради чего продукт и существует. Опасна не краткость, а
**безосновательность**, и проверять надо результат, а не отсекать вход.

Конструкция (по убыванию надёжности):
1. **`grounding::check`** — детерминированная проверка ответа по записи: каждое имя,
   число и латинское слово обязано опираться на расшифровку. Не опирается → модели
   дают один шанс переизложить (список улик ей НЕ показываем — иначе она их просто
   вычёркивает, «отмывая» выдумку); настаивает → результат ложится **черновиком**
   `*.unverified.md` с шапкой, а чистый файл стирается. Ничего не теряем, но и за
   факт не выдаём. Морфология и близость строк — библиотеки (`rust-stemmers`,
   `strsim`, `deunicode`), сравнение по транслитерированным ключам.
2. **Форма следует за входом** — короткая запись получает `note-ru` (выжимка), а не
   протокол с разделами «Решения» и «Поручения»: схему, которую велено заполнить,
   модель заполнит выдумкой. Явно выбранный `--summary-template` не перекрываем.
3. **Глоссарий по вхождению** — в промпт только реально звучавшие термины.
4. **Промпт** — запрет достраивать «типичную встречу». Самый ненадёжный рубеж.
Единственный оставшийся порог — не эвристика, а факт: ноль распознанных слов.
Плюс **`refine` проверяется построчно** (он становится best, то есть самой
расшифровкой — всё, что он допишет, дальше «обосновано» по определению) и
кнопка **«♻ Переварить заново»**: производное одноразово, аудио неприкосновенно.

Ревью (50 агентов, 27 подтверждённых находок) разнесло первую версию проверки, и
по делу: посимвольный Левенштейн между алфавитами всегда максимален → «слак»→Slack,
«Антропику»→Anthropic НИКОГДА не засчитывались как починка (26 ложных «выдумок» на
настоящем протоколе репозитория); на расшифровке в 4000 слов 9 из 13 выдуманных имён
«чинились» об случайные слова; наши же таймкоды `(MM:SS)` обосновывали любое число до
59. Всё исправлено, регресс на реальных артефактах в репозитории (`real_grounding.rs`).
