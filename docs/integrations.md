# Слоты и интеграции — как настроить и пользоваться

**Слот** — это голосовое имя назначения: «запиши **в идеи** …». Больше ничего:
имя, пара алиасов и указание, куда физически класть заметку.
**Интеграция** — это само «куда»: пока два вида — `files` (файл или папка на
диске) и `mcp` (любой MCP-сервер).

## Настройка за 30 секунд

1. Скопируй `slots.example.toml` → `slots.toml` (лежит рядом с exe или путь в
   env `LOCALVOX_SLOTS_CONFIG`).
2. Опиши слоты. Минимальный рабочий конфиг — 3 строки:

```toml
[slots."идеи"]
path = "D:/vault/Входящие/Идеи.md"
default = true
```

Всё: `localvox-note "мысль"` допишет в конец файла строку
`- 2026-07-11 17:39 — мысль`.

У каждого слота есть поле `type` — вид интеграции. `type = "files"` подразумевается,
если поле опущено (потому минимальный пример такой короткий); для MCP пишется
`type = "mcp"` явно.

## Варианты

**Файл (append):** путь оканчивается на `.md` — каждая заметка = строка в конце
по шаблону. Шаблон настраивается, плейсхолдеры `{{text}}`, `{{date}}`, `{{time}}`:

```toml
[slots."ретро"]
aliases = ["в ретро", "ретро песня"]
path = "D:/vault/Музыка/Ретро.md"
template = "- {{text}}"
```

**Папка (файл на заметку):** путь без расширения — каждая заметка становится
отдельным md-файлом `20260711-173941-первые-слова.md` (инбокс в стиле
Zettelkasten):

```toml
[slots."входящие"]
path = "D:/vault/Входящие"
template = "{{text}}"
```

**MCP (универсальный мост):** заметка уходит вызовом инструмента любого
MCP-сервера — Obsidian-MCP, Notion, самописный. Мы запускаем сервер (stdio),
вызываем `tools/call`, кладём текст в указанный аргумент:

```toml
[slots."обсидиан"]
type = "mcp"
command = "npx"
args = ["-y", "obsidian-mcp-server"]
tool = "append_content"          # имя инструмента у сервера
text_arg = "content"             # куда положить текст заметки
[slots."обсидиан".static_args]   # постоянные аргументы инструмента
filename = "Входящие/Идеи.md"
```

Замечание: для Obsidian обычно достаточно `files` — vault это просто каталог
с md-файлами, и файловый слот в него пишет без каких-либо серверов. MCP нужен,
когда хочется именно через плагин (или для Notion и прочих облачных).

## Использование

```
localvox-note "текст"                    # в default-слот
localvox-note --slot "в идеи" "текст"    # по имени или алиасу, без регистра
localvox-note --list                     # какие слоты настроены
```

Голосовой модуль дергает ровно этот же механизм: «запиши в слот идеи …» →
`resolve("идеи").write_note(текст)`.

## Голосовые активаторы

По умолчанию команда одна — «запиши» (`LOCALVOX_LIGHT_VOICE_TRIGGER`). Свои
активаторы — секцией `[commands]` в том же slots.toml:

```toml
[commands."запиши"]        # обычная команда: слот берётся из фразы («в идеи …»)

[commands."запомни"]       # активатор с жёстким слотом: адрес в речи не нужен
slot = "идеи"              # «запомни купить кофе» → сразу в «идеи»

[commands."отметь мысль"]  # активатор из нескольких слов
slot = "входящие"
```

## Ретро-режим: «запиши это»

Мысль уже прозвучала (твоя или собеседника из звонка) — повторять не нужно:
«**запиши это**» / «запиши это в идеи» / «запомни это» забирает **последние
30 секунд разговора** (микрофон + системный звук, `LOCALVOX_LIGHT_RETRO_WINDOW_SEC`)
и кладёт текст в слот. Собственные фразы ассистента в захват не попадают.
«Запиши это надо сделать» — обычная заметка с текстом «это надо сделать»
(ретро срабатывает, только когда после «это» пусто или чистый адрес слота).

## Как заканчивается заметка

Заметка **копится через паузы** — можно диктовать несколькими фразами. Конец:

1. **стоп-слово отдельной фразой**: «всё», «конец», «стоп», «хватит»
   (настраивается `LOCALVOX_LIGHT_NOTE_STOP_WORDS`);
2. **тишина** дольше 3.5 с (`LOCALVOX_LIGHT_NOTE_IDLE_SEC`);
3. **новая команда** («запиши…») — закрывает предыдущую заметку и открывает новую;
4. максимум 90 с диктовки.

Ход записи виден в статус-строке TUI: `● заметка [идеи]: 2 фразы — говорите…` →
`✓ записано в [идеи]: …`. Пока идёт диктовка, ассистент молчит (чтобы не перебивать
запись); подтверждение «Готово, записал: …» звучит по закрытии
(`LOCALVOX_LIGHT_VOICE_CONFIRM=off` — тихий режим). Команда без текста («запиши»)
отвечает «Слушаю…» и ждёт первую фразу до 20 секунд.

## Правила

- Кириллические имена секций — в кавычках: `[slots."идеи"]` (требование TOML).
- `default = true` — ровно у одного слота (туда падает «запиши» без адреса).
- Пути в конфиге — в нативном виде (`D:/...` или `D:\\...`), не Git Bash `/d/...`.
- Файлы и каталоги создаются при первой записи; append не портит чужие строки.
