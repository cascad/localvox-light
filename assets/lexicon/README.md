# Свои словари (лексикон)

Файлы `*.toml` в этом каталоге по умолчанию **дополняют** встроенные словари
localvox. Добавив одно имя коллеги, вы не потеряете остальные восемьдесят.

Каталог задаётся переменной `LOCALVOX_LEXICON_DIR` (по умолчанию — этот).
Встроенные значения лежат в `crates/localvox-light-core/lexicon/`.

## Заменить словарь целиком

Дополнение — это дефолт, а не тюрьма. Любой встроенный словарь можно **выбросить**
и поставить свой:

```toml
replace = ["names"]              # снести ВСЕ накопленные имена…
names = ["Кассандра", "Аполлинария"]   # …и оставить только эти
```

Виды для `replace`: `names`, `abbreviations`, `numerals`. Файлы читаются в
алфавитном порядке, поэтому `replace` удобно держать в `00-base.toml`, а свои
добавления — в `10-team.toml`.

Зачем это нужно: вшитый список без возможности его выбросить — жёсткая завязка.
Наши имена могут вам не подходить (другой язык, другая предметная область), и
деться от них должно быть куда.

Зачем это нужно: проверка обоснованности (`grounding`) сверяет протокол с
записью и не даёт модели выдать за факт то, чего не звучало. Чтобы она не
ошибалась на ваших данных, ей нужны ваши имена и ваши аббревиатуры.

## Пример: `my.toml`

```toml
# Имена коллег и клиентов. Имя проверяется как ЧЕЛОВЕК: независимо от позиции
# в строке и по строгому правилу (одна правка на падеж). Если модель напишет
# «Кассандра сделает отчёт», а в записи Кассандры не было, — это выдумка,
# и протокол уйдёт в черновик с пометкой.
names = ["кассандра", "аполлинария"]

# Аббревиатуры вашей предметной области. Фактов они не несут (ни человека, ни
# срока, ни количества), поэтому на обоснованность НЕ проверяются — иначе они
# дают ложные тревоги: короткое слово транслитом ни с чем не сопоставляется.
abbreviations = ["сбп", "фот", "рсбу"]

# Числительные словами → значение. Нужны, чтобы «больше ста пятидесяти» в
# протоколе сверялось с «150» в записи (и наоборот).
[forms]
"полтора" = 1
"дюжина" = 12
```

Битый файл — громкая ошибка в логе, а не тихий пропуск: работать с половиной
словаря хуже, чем упасть.
